# 시연 데이터 안내

> [!abstract] 패키지 준비 완료
> 첫 시연용 합성 데이터, 정상 분배·소급·잔여금 기대값, 독립 시나리오 21건을 준비했다. 앱에 적재하거나 시스템을 시험한 결과는 아니며, 데이터 패키지의 산술·참조·파일 일관성을 확인한 상태다.

## 구성

- 권리자 5명, 사용자 역할 8개, 저작물 3개, 이용계약 2개, 모의 신탁계약 1개, 요율 2개, 사용자료 2건.
- 초기 지분 5행, 정정 지분 2행, 분배 기대값 5행, 조정 기대값 2행.
- 신청→보완→재제출→승인→모의서명 이벤트 5건.
- 원본 대체 텍스트 7개, 공개/권리/정산 지식 문서 3개.
- 정상·재현 시나리오 3건, 예외·통제 시나리오 18건.

## 적용 경계

이름·저작물·식별자·규칙·문서 모두 내부 작성 합성 예시다. 실제 주민번호·계좌·IPI·ISWC·서명·음원은 포함하지 않았다. 신탁·입금·서명·지급은 모의 또는 초안이며 실제 송금 요청은 생성하지 않는다. 실제 협회 규칙·세금·수수료·소급 지급 후 환수는 이번 예시에서 다루지 않는다. OCR용 이미지와 학습용 음원도 포함하지 않는다.

JSON의 시나리오 patch는 앱과 무관한 선언형 변경 명세다. 각 예외를 BASE001 복제본에서 독립 적용하고, 앱의 API·테이블에 연결하는 적재기는 후속 구현한다. 매칭 점수·응답 정책은 시연 기대값이며 모델 실측 성능이 아니다.
