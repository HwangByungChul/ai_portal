# 단계별 실행계획과 자원 산정

## 일정 가정

사용자 확인 목적은 제안·시연이다. **인원·가용시간·예산·목표일이 미확정이므로 아래 기간은 산정용 초안이며 납기 약속이 아니다.** 전담 4~6명 수준의 팀과 정기적으로 참여하는 업무 검토자가 있다고 가정한다. 겸직·소수 인력이면 첫 시연 범위를 조정하고 다시 산정한다.

| 단계 | 상대 기간 제안 | 핵심 작업·산출 | 종료 기준 |
|---|---|---|---|
| D0 범위·규칙·설계 | 착수 후 1~2주 | 시연 상세, 권한·상태·합성 데이터·기대값, 구조 초안 | 내부 책임자가 첫 시연 범위 승인 |
| D1 연결 시연 | 이후 6~10주 | 공통, 회원·권리, 사용자료·매칭·금액, 포털 조회, 작은 근거 응답 | 정상·예외·재현·권한·금액 시험 통과 |
| D2 전체 영역 확장 | 이후 3~6개월 검토 | 센터·경영 상세, 앱, OCR·그래프·RAG 운영, 국제 포맷·모의기관 확장 | 전체 범위표의 시연 대응·제약·증빙 확보 |
| D3 운영 적합성 | 실제 도입 결정 후 별도 산정 | 실제 규칙·데이터·기관, 이관·성능·보안·DR·사용자 인수 | 도입기관 합의 기준으로 검증 |

D1은 내부 준비가 갖춰진 후 약 8~12주를 검토할 수 있다. D2의 전체 요구사항 충족을 3~6개월에 보장하는 의미는 아니다. 상세 기능 분해와 D1 생산성 측정으로 다시 산정한다. RFP 24개월은 원 발주 사업 기간이며 내부 데모 일정에 그대로 적용하지 않는다.

## D1 작업과 의존성

| 작업 ID | 작업 | 선행 | 담당 역할 제안 | 검증 |
|---|---|---|---|---|
| W01 | 시연 흐름·규칙·기대값 확정 | 없음 | 제품/업무 리드 | 시나리오 승인 |
| W02 | 저장소·환경·배포·초기화 | W01 | 개발/운영 리드 | 초기 데이터 재현 |
| W03 | 사용자·권한·감사·파일·상태 | W02 | 공통 개발 | 본인/타인 접근 시험 |
| W04 | 회원·신탁·저작물·지분·시점 | W01,W03 | 업무 개발 | 승인·반려·지분·이력 |
| W05 | 사용자료·중복·오류·작업 큐 | W02,W03 | 데이터 개발 | 파일·건수 대사 |
| W06 | 후보·근거·검수·매칭결정 | W04,W05 | AI/업무 개발 | 오매칭·수동 전환 |
| W07 | 정산·모의청구/입금·분배·정정 | W04,W06 | 업무 개발 | 기대값·합계·소급 대사 |
| W08 | 홈페이지·포털·본인조회 | W03,W04,W07 | 화면 개발 | 회원/담당자 연결 |
| W09 | 내부 지식·권한·근거응답 | W03 | AI 개발 | 미근거·타인정보 차단 |
| W10 | 통합시험·제약표·시연 자료 | W06~W09 | 품질/업무 검토 | 승인 시나리오와 증빙 |

W08 화면 흐름은 W01 이후 먼저 설계하고, 데이터 연결은 선행 작업 완료 후 한다. W09는 핵심 금액 흐름의 납기에 영향을 주면 독립 시연으로 분리할 수 있다. 전체 범위에서는 계속 관리한다.

## 역할과 투입

필요 역할은 제품/업무 책임, 백엔드·권리/정산, 프론트·UX, 데이터/AI, 환경·품질이다. 한 사람이 겸할 수 있지만 금액 규칙 승인과 테스트 결과 검토에는 구현자 외 검토자를 둔다. 가정상 4~6명은 역할 조합이며 각 전문 인력을 별도로 확보했다는 뜻이 아니다. 권리·정산 규칙 경험이 없는 경우 현업/도메인 검토 참여가 가장 중요한 의존성이다.

## 비용 산정 틀

금액은 견적 없이 확정하지 않는다. `인건비 = 역할별 인월 × 내부 원가`, `서비스비 = 환경별 월 자원비 × 개월 + AI 요청/토큰비 + OCR 처리비 + 저장/전송비`, `총 투자 = 인건비 + 서비스비 + 도구/라이선스 + 도메인 검토 + 운영/유지 비용 + 승인된 예비비`로 산정한다.

- D1 가정: 4~6명 × 약 2~3개월 = 8~18인월. 초기 계획 비교용이며 기능별 산정 전 수치다.
- 개발·시연·운영 환경의 비용을 구분하고 비사용 시연 자원의 종료·데이터 초기화를 관리한다.
- AI 예산 상한·알림·요청 제한을 설정한다. RFP의 예산 비율이나 설명회의 비용상한을 내부 예산으로 적용하지 않는다.
- 외부 유료서비스·상용 라이선스·실제 기관 연계는 필요성이 확인된 후 별도 결정한다.

## 검토 주기

주간: 시연 가능한 기능·블로커·금액/권한 결함·추적대장 갱신. 격주: 실행 시연과 범위 재평가. 단계 종료: 기대값 대사·시험·제약표 승인. 새로운 기능은 원문 근거·목적·작업량·납기 영향을 기록하고 다음 릴리스에 배치한다.
