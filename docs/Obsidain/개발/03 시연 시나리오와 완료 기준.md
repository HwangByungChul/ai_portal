# 시연 시나리오와 완료 기준

## 제안용 핵심 시연 — 15~20분 구성 제안

| 순서 | 장면 | 보여줄 가치 | 완료 증거 |
|---|---|---|---|
| 1 | 회원이 가입·신탁 신청·증빙 제출 | 비대면 신청과 진행상태 | 신청 ID가 담당자 처리함에 동일하게 표시 |
| 2 | 담당자 반려→회원 보완→승인·모의 계약 | 업무 단절 해소 | 상태·사유·승인자·모의서명 표시 |
| 3 | 저작물·권리자·지분 등록, 기준일 확정 | 권리 이력과 특정시점 재현 | 시점별 지분과 규칙 버전 표시 |
| 4 | 사용자료 파일 수집, 오류 격리 | 품질·중복 방지 | 원본→정규화→오류·정상 건수 대사 |
| 5 | 후보 추천·자동/수동 매칭·반려 | 설명 가능한 자동화 | 후보·점수·근거·검수자·결정 이력 |
| 6 | 요율로 정산→청구·모의 입금→분배 | 금액의 재현성과 추적 | 입력·산식·지분·잔여금·결과가 연결 |
| 7 | 회원 본인 분배조회·이의접수 | 서비스 완결성과 권한 | 본인 자료만 조회, 타인 조회 거부 |
| 8 | 권리변경 소급과 재산출, 근거 질의 | 변경 대응·지능형 업무 지원 | 원결과 유지·조정 내역·근거 문서·버전 |

전자서명·본인인증·입금·지급·외부기관 응답은 초기에는 모의 처리임을 화면과 시연 설명에 표시한다. 모델을 호출하지 않는 추천 기능은 규칙 기반으로 표시한다. 데이터는 합성·시연용임을 표시한다.

## 합성 데이터와 금액 기대값

내부 작성 예시이며 실제 협회 요율·분배 규칙을 나타내지 않는다. 권리자 A/B, 저작물 W1, 사용자료 U1/U2, 계약 C1, 규칙 R1을 만든다. 금액 계산은 고정 소수점 또는 최소 통화단위 정수로 구현하고 부동소수점 연산을 피한다.

- 1차: U1 100회 × 예시 요율 100원 = 10,000원. 지분 A 60% / B 40% → 6,000원 / 4,000원.
- 소급 예시: 승인된 정정 지분 A 50% / B 50% → 5,000원 / 5,000원. 원결과는 보존하고 조정액 A -1,000원 / B +1,000원을 별도 기록한다.
- 잔여금: 예시 금액 1,001원, 동일 지분 3인. 절사 후 각 333원과 잔여 2원을 기록하고, 내부 승인된 고정 순서로 2인에게 1원씩 배정한다. 결과 합계는 1,001원이다.
- 예외: 지분 합이 기준에 미달/초과, 효력기간 중첩, 동일 파일 재접수, 오매칭, 계약 미승인, 미입금, 본인 외 조회, 원본 누락을 각각 준비한다.

징수액·차감·보류·분배·지급은 서로 다른 상태와 금액으로 관리한다. 예시는 수수료·세금이 없는 단순 규칙이며 실제 규칙은 후속 명세와 검토가 필요하다.

## 시연 개발 합격 기준 제안

| 항목 | 내부 완료 기준 |
|---|---|
| 업무 연결 | 승인된 정상 시나리오의 모든 단계가 동일 ID로 추적됨 |
| 금액·재현 | 예시 기대값 일치, 동일 입력·시점·규칙의 결과 동일, 합계 차이 0원 |
| 예외·재실행 | 실패 건 격리·재실행, 동일 요청 재전송 시 계약·금액 중복 생성 없음 |
| 권한 | 본인·부서 권한 시나리오에서 타인정보 접근 거부 확인 |
| 이력 | 수정·승인·매칭·분배·정정의 전후값과 근거 추적 |
| AI | 근거 문서 확인, 근거 없는 질문의 확인 불가 응답, 검수·수동 전환 실행 |
| 재현성 | 정해진 초기 데이터로 시연 초기화·반복 실행 가능 |
| 공개 표현 | 구현·모의·미구현 기능을 데모 화면·범위표에 표시 |

소량 시연 성공은 RFP의 실데이터 AI 품질·일 1억 건 처리·운영 전환 완료 증거가 아니다. 해당 항목은 [[개발/06 요구사항 추적대장]]에 후속 검증으로 남긴다.

## 보관할 시연 자산

시연 스크립트, 초기 데이터 버전, 기대값·실제값 대사표, 테스트 결과, 화면/영상, 알려진 제약, 배포·초기화 절차를 같은 릴리스 버전에 연결한다. 외부에 제안할 때 특정 기관의 이름·자료·규칙 사용 가능 여부를 확인하고 승인된 자료만 사용한다.
