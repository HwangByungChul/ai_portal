# 전체 구축 범위와 단계별 대응

RFP PDF p.35~38의 사업범위와 상세 SFR p.56~154를 기준으로 재구성했다. 아래 단계 배치는 내부 개발 권고안이다. 전체 범위를 삭제하지 않고 최초 시연 이후에도 추적한다.

단계: **D0 설계·데이터 준비 / D1 연결 시연 / D2 영역 확장 / D3 운영 적합성 검증**. D3는 실제 도입이 결정될 때 실행하는 검증 범위이며 완료 일정은 미확정이다.

## 범위 완료를 판단하는 방법

요구사항 한 건에 여러 기능이 들어 있으므로 103건의 ID 체크만으로 전체 구축 완료를 판단할 수 없다. 개발 시 상세 조항을 하위 기능으로 나누고 `내부 기능 ID → 원문 ID와 페이지 → 화면/API/규칙 → 테스트 → 증빙`을 연결한다. 모의 연계도 같은 기능에 기록하지만 실제 연계 완료 상태와 분리한다.

계약·인력·하도급 조건은 [[개발/06 요구사항 추적대장]]에서 내부 거버넌스로 전환하거나 장래 계약 시 검토할 항목으로 남긴다. 미적용 사유가 없는 자동 제외는 금지한다.
