# 요구사항 추적대장

## 기준과 불일치

사전규격 RFP 총괄은 104건이다. 목록 p.40은 SFR-012 회원용 앱 중복과 SFR-013 AI를 표기하지만 상세 p.150은 SFR-012 AI로 되어 있어 **상세 고유 ID 103건**을 기준으로 추적한다. SFR-013을 삭제하거나 추가 기능 완료로 간주하지 않고 ISSUE-001에서 매핑 충돌로 관리한다. CSR-001도 목록과 상세 명칭이 다르다.

아래 모든 건은 미착수다. 내부 추적 ID `DEV-원문ID`는 원문 상세 위치에 고정한다. 단계·적용유형은 내부 시연 목적에 맞춘 초안이며 원문 요구를 면제하는 판단이 아니다. 특히 계약 관련 요구는 내부 거버넌스나 장래 계약 검토로 전환하되 적용 사유를 남긴다.

## 적용유형과 증빙

| 유형 | 내부 대응 | 검증증빙 |

| 업무구현 | 기능·데이터·API·규칙 | 시나리오·화면·감사·결과 대사 |
| 플랫폼·품질 | 환경·성능·테스트·보안·데이터 | 설계·측정·시험·결과서 |

| 장래 계약 검토 | 하도급·기관 귀속·배상·인력승인·하자 | 적용 검토와 실제 계약의 별도 기준 |
