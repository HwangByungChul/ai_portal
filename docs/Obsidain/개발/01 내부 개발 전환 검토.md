# 내부 개발 전환 검토

## 검토 결론

**전체 범위를 향후 제안·시연 자산으로 개발하는 방향은 타당하다. 다만 실제 협회 차세대 운영 전환과 동일한 완성도를 초기 목표로 잡으면, 접근할 수 없는 현행 업무·데이터·대외 연계 때문에 비용과 일정의 불확실성이 커진다.** 전체 범위는 유지하고, 단계별로 실행 가능한 시연과 검증 증거를 축적하는 방식으로 추진한다.

사용자는 2026-10-04 우선 목적을 향후 유사 사업 제안·시연으로 확인했다. 인원·예산·목표일은 아직 확인되지 않았다. 아래 구조·순서·자원안은 검토 제안이며 확정 계획이 아니다.

## 제안 당시와 달라진 점

| 항목 | 기존 사업 제안 | 내부 개발 판단 |
|---|---|---|
| 책임 범위 | KT 협력 수행 제안은 회원 Front·신탁관리 중심 | 징수분배·센터·경영·AI·데이터·인프라·운영까지 전 범위 추적 |
| 성과 | 협회 검수·현행 서비스 전환 | 실행되는 업무 흐름·재현 가능한 시연·구현 근거 |
| 데이터 | 협회 원천·현행 DB·규정·SP 접근 필요 | 합성 데이터·내부 작성 규칙으로 시작, 실데이터 검증은 후속 |
| 대외 연계 | 실제 기관·계약·인증·사양 확보 | 어댑터와 모의 응답, 실제 연결 여부를 명시 |
| 일정 | RFP 계약 후 24개월 | 인원과 시연 범위에 따라 재산정 |
| 예산 | 내부 제안자료의 100억 원 가정 | 내부 투자 예산과 무관, 인건비·서비스·운영비로 산정 |
| 계약 조항 | 하도급·인력증빙·귀속·하자 등 발주 계약 기준 | 내부 개발의 자동 적용 조건 아님, 장래 계약별 재검토 |

근거: RFP PDF p.9, p.35~43, COR/PMR/PSR; 기존 KT 협력 수행 제안 최종본 슬라이드 2·5·8·10. 기존 예산은 공식 확정액으로 사용하지 않는다.

## 우선 확보할 자산

1. **권리와 금액 모델:** 유효시점·등록시점·지분·규칙 버전·소급·잔여금·대사의 설명 가능한 구현.
2. **연결된 화면:** 회원과 담당자 역할을 바꾸며 같은 신청·저작물·분배결과를 추적하는 업무 시연.
3. **AI 검수 흐름:** 매칭 후보와 근거, 원본과 OCR 결과, 권한에 맞는 지식 응답 및 수동 전환.
4. **제안 증빙:** 범위표·구조도·시연 기록·시험 결과·구현/모의/미구현 현황.
5. **재사용 구조:** 기관별 규칙·서식·명칭·연계 설정을 분리하고 특정 협회의 실데이터 없이 실행 가능한 패키지.

## 실행 순서 판단

첫 착수 대상은 공통 권한·감사이력, 회원·신탁·저작물·지분, 작은 사용자료와 결정론적 금액 산출이다. AI 매칭은 규칙 기반 후보·검수부터 붙이고, RAG/OCR은 별도 데이터셋으로 품질을 측정한다. 일 1억 로그·대용량 이관·실제 지급·전체 외부기관 연계는 후속 검증 단계로 유지한다.

업무 화면이 보이는 것과 운영 가능한 것은 구분해야 한다. 시연 수준만 충족한 기능을 RFP 준수·운영 검증 완료로 표시하지 않는다. AI 성능, 대량 처리, 실제 전자서명·은행 연계는 각각 실측 또는 계약·기관 검증 근거가 있어야 주장할 수 있다.

## 착수 판단

시연 개발은 현재 자료만으로 범위 설계와 합성 데이터 준비를 시작할 수 있다. 전체 개발 완료일·총원가는 인원과 목표 수준이 정해진 후 확정한다. 운영 전환은 현행 자료 접근, 실제 업무 담당자 검증, 이관·대사·성능·복구 검증이 확보된 이후 별도로 판단한다.
