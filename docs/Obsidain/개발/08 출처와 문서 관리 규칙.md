이번 검토는 제공된 로컬 자료 분석이다. 외부 웹 조사, 최종 공고 검색, 라이선스·법률 검토, 개발 구현, 성능 시험은 수행하지 않았다. 기술 제품·모델·법적 효력의 최신 정보를 확정하지 않았다.

## 원문 대조에서 확인한 정정·쟁점

- RFP p.40 목록은 SFR-010 회원용 앱, SFR-011 출장용 앱, **SFR-012 회원용 앱(중복), SFR-013 AI**를 기재한다. p.150 상세는 **SFR-012 AI**다. 상세 고유 ID는 103건이며 총괄은 104건이다. 기존 노트의 ‘상세 103건’ 판단을 유지하되 목록의 중복과 SFR-013 존재를 추가 기록했다.
- CSR-001은 p.39 목록 ‘표준 UI/UX 설계요건’, p.44 상세 ‘현행 업무·정보시스템 분석’으로 다르다. 이름만으로 기능을 제외하지 않는다.
- 기존 범위 노트는 공식 9개 워크스트림으로 재구성했지만 원문 p.35~38의 번호는 (1)~(5), (7)~(9)다. 운영·안정화는 다른 요구에서도 관리하므로 원문 번호와 내부 묶음 수를 구분한다.
- 페이지를 넘어가는 PER-003·QUR-002·QUR-003·PMR-007은 이어지는 페이지의 명칭을 연결하여 추적했다. 자동 추출 누락을 요구 누락으로 처리하지 않는다.

## 관리 규칙

모든 개발 노트는 `title`, `created`, `updated`, `status`, `purpose`, `tags`를 갖는다. 현재 문서는 1차 검토 초안이다. 확인된 사용자 결정과 검토 제안·산정 가정을 구분하고, 갱신 시 날짜·근거·변경 영향을 남긴다.

- 관리 위치: BNK 프로젝트의 `10.Obsidain/그룹 공동 생성형 AI 플랫폼/개발`. 홈은 [[개발/00 개발 대시보드]].
- 기존 제안 문서와 원본 PDF/PPTX는 수정하지 않는다. 관련 노트·원문을 내부 링크로 연결한다.
- 새 세부 산출물은 `개발/설계`, `개발/시연`, `개발/검증`, `개발/운영` 아래에서 필요한 시점에 만든다.
- 기존 저작권 정보시스템의 요구 추적은 [[개발/06 요구사항 추적대장]]에 보존한다. 현재 BNK 플랫폼 기준은 [[개발/AI 통합 포털/05 BNK 플랫폼 기준 정정과 개인 MVP]]를 우선하며 요구 추적을 혼용하지 않는다.
- 상태는 미착수 / 설계중 / 구현중 / 시연검증 / 운영검증 / 보류로 관리한다. 모의 여부는 별도 필드로 둔다.
- 외부 공유본에는 실제 기관 자료·협력사·인력·경쟁 정보 포함 여부를 별도로 확인한다.
