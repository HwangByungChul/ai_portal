# 400.프로젝트관리

목표: 진행·의사결정·변경·리스크·결함을 전 단계에서 관리한다.

현재 상태: **검토중**. 폴더 생성은 단계 완료를 의미하지 않는다.

## 관리 항목

- 선행 입력 및 관련 요구사항
- 계획 산출물과 문서 ID
- 작성·검토·확정 상태
- 실제 구현·시험 증거 위치
- 미결정 사항 및 다음 단계 전달사항
