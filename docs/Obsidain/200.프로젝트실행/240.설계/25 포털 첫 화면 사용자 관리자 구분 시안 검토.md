# 포털 첫 화면 사용자 관리자 구분 시안 검토 및 적용
> [!success] 사용자 확정 사항 (2026-10-17)
> 사용자와 관리자 사이트의 첫 화면 구분을 위해 제시된 시안 중 **시안 1 [기능 및 도메인 정체성 차별화 안]**을 채택·확정했습니다. 이에 따라 실제 프론트엔드 공통 패키지(`packages/ui`) 및 앱에 시안 1 설계를 반영 완료했습니다.

## 1. 확정 배경 및 목적
- **기존 문제**: 로컬 환경에서 사용자 웹(포트 5173, `apps/user-web`)과 관리자 웹(포트 5174, `apps/admin-web`) 기동 시, 비인증 상태의 첫 화면이 동일한 컴포넌트(`LoginPage.tsx`)를 단일 렌더링하여 화면상으로 업무 포털과 관리자 콘솔을 전혀 구별할 수 없었습니다.
- **개선 목표**: 기존의 친숙하고 검증된 2분할(좌측 브랜드 비주얼 + 우측 인증 폼) 레이아웃은 유지하되, **테마 컬러, 브랜드 심볼, 메인/서브 카피, 3선 안내, 인증 뱃지 및 보안 경고**를 명확히 분리하여 첫 진입 시 도메인 정체성을 즉각 인지하도록 구현합니다.

## 2. 확정된 시안 1 상세 구성

### 사용자 사이트 (포트 5173 · 임직원 AI 업무 공간)
- **테마 컬러**: 딥 틸(`Deep Teal #087f78`) & 에메랄드 그라데이션 + 화이트 폼
- **브랜드 마크**: `✨ AI WORKSPACE` (지능형 업무 비서 심볼)
- **메인 카피**: "스마트한 업무의 시작, <br>생성형 AI 플랫폼."
- **서브 카피**: "사내 표준 Agent와 안전한 문서 분석을 통해 일상 업무의 생산성과 혁신을 경험하세요."
- **핵심 안내 3선**:
  - `01` 스마트 AI 대화 & 보고서 작성
  - `02` 표준 업무 Agent 카탈로그
  - `03` 안전한 사내 문서 요약 분석
- **인증 폼 영역**:
  - 상단 뱃지: `WELCOME BACK · USER WORKSPACE`
  - 폼 타이틀: **"임직원 로그인"**
  - 입력 레이블: "로그인 ID", "비밀번호" (안내: `사번 또는 계정 ID`)
  - 버튼 문구: "로그인" (딥 틸 테마)
  - 하단 안내: "계정과 조직 권한은 부서 관리자에게 확인해 주세요."

### 관리자 사이트 (포트 5174 · 엔터프라이즈 운영 통제 센터)
- **테마 컬러**: 다크 인디고/슬레이트 차콜(`Slate Navy #0f172a` / `#1e293b`) + 사이언 블루 & 앰버 보안 포인트
- **브랜드 마크**: `🛡️ ADMIN CONSOLE` (보안 방패 및 시스템 통제 심볼)
- **메인 카피**: "엔터프라이즈 AI 거버넌스, <br>운영 통제 센터."
- **서브 카피**: "AI 자산 배포 승인, 모델 라우팅, 보안 가드레일 및 조직별 사용량과 비용을 안전하게 통합 관제합니다."
- **핵심 안내 3선**:
  - `01` **Agent 배포 심사** 다단계 승인·검증 워크플로우
  - `02` **운영 지표 관제** 실시간 호출 통계 및 조직별 토큰 한도
  - `03` **보안 가드레일** 데이터 반입 심사 및 안전 정책
- **인증 폼 영역**:
  - 상단 뱃지: `🛡️ OPERATIONS CONSOLE`
  - 폼 타이틀: **"관리자 콘솔 인증"**
  - 보안 안내: 로그인 후 계정의 관리자 권한에 따라 관리 기능 접근이 결정됨을 표시합니다. 접속 감사 로그의 구현이 확인되지 않아 기존의 로그 기록 단정 문구를 제거했습니다.
  - 입력 레이블: "관리자 계정 ID", "비밀번호" (안내: `관리자 계정을 입력하세요`)
  - 버튼 문구: "관리자 인증 및 로그인" (다크 슬레이트 테마)
  - 하단 안내: "관리자 권한 신청 및 보안 세션 문의는 시스템 운영팀에 문의하세요."

## 3. 실제 변경 파일 및 구현 내역
1. **`src/frontend/packages/ui/src/LoginPage.tsx`**:
   - `site?: 'user' | 'admin'` prop 분기 추가.
   - `isAdmin` 플래그에 따라 좌측 웰컴 패널(심볼, 카피, 3선 특징, 푸터)과 우측 로그인 패널(뱃지, 타이틀, 보안 알림, 버튼 텍스트, 안내) 조건부 렌더링.
2. **`src/frontend/packages/ui/src/PortalShell.tsx`**:
   - `state.phase === 'login'` 상태에서 `LoginPage` 호출 시 현재 셸의 `site` prop(`user` 또는 `admin`)을 전달하도록 연계.
3. **`src/frontend/src/App.tsx`**:
   - 단일 앱 호환 엔트리포인트에서 `adminViews.includes(view)` 여부에 따라 `LoginPage`에 적절한 `site` prop 전달.
4. **`src/frontend/packages/ui/src/styles.css`**:
   - 관리자 웰컴 패널 그라데이션(`linear-gradient(150deg, #090d16 0%, #0f172a 50%, #1e293b 100%)`), 격자 배경 패턴, 관리자 뱃지(`admin-badge-logo`), 안내 박스(`admin-feature-row`), 보안 알림 박스(`security-alert-box`), 관리자 전용 버튼 스타일 추가.
