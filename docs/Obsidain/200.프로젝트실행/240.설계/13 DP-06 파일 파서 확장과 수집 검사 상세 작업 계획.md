# DP-06 파일 파서 확장과 수집 검사 상세 작업 계획

> 상태: 다음 작업 계획. 구현 전 상세 설계와 형식별 수용 기준을 확정한다. 일정 마감은 적용하지 않는다.

## 목적과 선행 조건

[[12 DP-05 개인 문서함 상세 설계]]의 본인 문서 등록·상태·게시·첨부·삭제 흐름에 업무 문서 형식을 단계적으로 추가한다. TXT/Markdown은 기준 회귀로 유지한다. 기존 상세 개발 계획의 DP-06은 DP-05와 DP-18에 의존하므로, 파일 형식을 허용하기 전에 **DP-18 중 수집·색인 경계의 최소 정책 검사**를 먼저 닫는다. DP-18 전체 정책 관리·예외 승인·출력 검증이 끝났다고 간주하지 않는다.

## 실행 단위

### DP06-P0: 최소 수집 정책 검사

현재 정책 통제 위치를 점검하고 DP-18의 attachment/index 경계를 구현한다. 합성 주민등록번호·계좌·전화·이메일과 알려진 문서 내 지시 공격 사례에 대해 탐지/허용/차단 정책을 정의한다. 초기에는 원본을 바꾸지 않는 차단 방식을 우선하여 인용 위치 불일치를 피한다. 검사 실패·정책 오류·미지원 형식은 게시와 외부 색인 호출 전에 차단한다. 원문과 민감 문자열을 일반 로그·감사에 기록하지 않는다. 합성 정상/오탐/미탐 사례 및 탐지 한계를 보고한다.

### DP06-P1: 공통 파서 계약과 텍스트 PDF

원본 바이트의 해시와 추출 텍스트의 해시를 구분하고 parser_version, 페이지, start/end를 보존한다. 현행 SourceStorage와 build_document_plan이 UTF-8 원문 하나를 전제하는 부분을 변경하기 전에 원본·추출물별 경로/읽기 권한/삭제 정리 계약을 설계한다. 원본은 불변으로 저장하고 추출물도 버전 단위로 관리한다. 제목·문서 ID·파일 이름은 권한이나 경로로 사용하지 않는다.

의존 라이브러리는 현재 환경과 공식 문서·유지보수·라이선스를 확인해 선정한다. 파서는 네트워크 접근 없이 제한된 별도 실행 단위에서 바이트/페이지/출력 문자/시간/메모리를 제한한다. 이미지 전용 PDF는 OCR 미지원으로 구분하며 빈 텍스트를 성공으로 게시하지 않는다. 암호 문서·첨부 파일·외부 참조·손상 파일의 처리 정책을 명시한다.

### DP06-P2: Office 형식별 확장

DOCX는 문단·표, XLSX는 시트·셀, PPTX는 슬라이드·텍스트 위치를 보존한다. ZIP 파일 수·압축 해제 합계·비율·중첩·경로 탈출·임베디드 실행 파일·매크로를 검사한다. 외부 링크를 가져오거나 매크로/수식을 실행하지 않는다. XLSX의 수식/저장 값은 구분하고 읽은 값의 정확성을 표시한다. 각 형식은 별도 시험을 통과한 뒤 화면 선택 목록에 추가한다. 한꺼번에 모든 형식을 지원한다고 표시하지 않는다.

### DP06-P3: 게시·근거·삭제·비용 회귀

처리 중/검사 실패/파서 실패는 질문 첨부에 나타나지 않는다. 게시 후 질문의 인용문과 페이지/시트/슬라이드 위치가 원문 fixture와 일치해야 한다. 삭제 시 원본과 추출물·색인 모두 정리하고 기존 대화의 접근 회수와 비용 원장 보존을 확인한다. 무중단 버전 전환은 기존 실행의 출처를 바꾸지 않는 계약을 별도 확정한 후 구현하며, 이번 파서 추가만으로 완료 처리하지 않는다.

## 핵심 수용 시험

1. 허용 MIME/확장자와 실제 형식이 일치한 파일만 접수한다. 위조된 파일은 미게시이며 임베딩 호출 0이다.
2. 페이지·표 숫자·시트 셀·슬라이드 인용이 형식별 fixture와 일치한다.
3. 암호/손상/압축 폭탄/경로 탈출/매크로/시간 초과는 안전한 실패 코드만 반환한다.
4. 현재 조직과 소유권을 검사 전·작업 중·게시 전·질문 접수·근거/원문 조회에서 재확인한다.
5. 같은 접수 ID는 파싱/색인 작업·비용을 중복 생성하지 않는다. 다른 원본은 충돌 처리한다.
6. 삭제 정리가 다른 문서에 영향을 주지 않으며 실행 출처·청구 원장은 보존한다.
7. 정책 오류 또는 차단 사례는 모델/임베딩 공급자 송신 0이다. 규칙 기반 검사의 한계도 함께 기록한다.

## 이번 계획에서 구분할 항목

OCR/HWP/URL 수집은 실제 엔진·시험 자료·비용·운영 범위를 확인하기 전까지 미지원이다. 파일 파서가 문서 내용의 지시를 실행하지 않으며, 추출 성공이 RAG 답변의 정확성을 보장하는 것으로 표시하지 않는다. 기본 검증은 합성 파일과 모의 공급자로 수행하고 실제 호출 여부는 별도로 기록한다.
