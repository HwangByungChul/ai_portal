# DP11-04 시험 증적 구현 결과

사용자 “네 진행 바랍니다” 승인으로 [[29 DP11-04 시험 이력 수동 평가와 버전 비교 상세 계획]]을 먼저 기록하고 실제 API·DB·React 개발을 진행했다. 사용자는 제안 기능을 서비스 오픈 수준으로 구현하도록 요구했으며, 현재 앱을 즉시 운영 배포하라는 뜻이 아니다. 개인 시험 이력·수동 평가·비교는 실제 저장/조회 구현이다. 자동 업무 품질 평가·동적 배포 승인/게시·기관 수용·운영 배포 완료로 확대하지 않는다.

## 실제 동작

- 자산별 본인 trial 이력을 최근순으로 최대20건씩 keyset pagination 조회한다. 페이지 재진입 후 다시 선택할 수 있다. 최소 목록은 run/version/revision/state/mode/purpose/시각만 제공한다. 다른 관리자도 타인 개인 입력·답변·평가를 열 수 없다.
- 증적 상세는 현재 세션/관리 권한/본인/조직/저장 profile와 자료 ACL을 재검사한다. 봉인된 버전·profile/조합/결과 SHA256·정확한 자료 binding·정산 상태·기존 고정 policy revision과 호출 원장 price snapshot을 반환한다. 새 API는 full messages/변수값/provider request ID/credential을 반환하지 않는다. 가격은 동결 내부 추정이며 실제 청구액이 아니다.
- migration033의 builder_assessments는 forced RLS와 capability RPC만 사용한다. 현재 본인 완료 결과에 manual-v1 정확성/업무 적합성1~5, 기대 답변/부족근거, 적합/보완/부적합, 의견최대1000자를 저장한다. 평가마다 result_hash/profile_hash와 작성시각을 봉인한다. UPDATE/DELETE는 권한·trigger로 차단한다. 재평가는 과거 기록을 보존하고 새 행으로 추가한다. 최근20건과 전체건수를 표시한다.
- 같은 client_request_id/같은 run+body는 동일 receipt, 변경은409. replay도 현재 자료 권한을 재검사한다. 화면은 접수 불명 시 같은 ID로 확인하고 추가 평가 중복을 막는다. 점수나 적합 판정이 자동 승인/게시를 만들지 않는다.
- 같은 자산의 본인 시험2개를 서버의 한 transaction에서 재검사하여 비교한다. 버전별 결과/평가/자료/지문/정산 상태를 표시한다. 동일 사용자 질문 지문·목적·모의/실제·자료·모델·정책revision·가격snapshot·양쪽 완료 여부를 명시한다. 서로 다른 조건을 무조건 우열로 표시하지 않는다. system/developer prompt 변경은 profile/조합 지문의 차이로 확인한다.
- React는 dirty 상태에서 증적을 숨기고 조직/자산 전환 시 응답을 폐기한다. 표시된 과거 증적은5초 간격으로 현재 권한을 재검사하며 실패하면 상세·평가 양식·비교를 지운다. 문서 회수 후 최소 이력 메타데이터는 유지하되 상세/평가/비교는404로 거부한다. 브라우저 캐시에 이미 전달된 내용의 소급 삭제를 보장한다는 의미는 아니다.

API: GET assets/{asset}/trials, GET trials/{run}/evidence, POST trials/{run}/assessments, POST trial-comparisons (모두 /api/v1/admin/builder). CSRF·허용 query/body·no-store·현재 세션·문서 read window를 유지한다. 공개 draft 실행404와 사용자 대화에서 private trial 숨김을 보존한다.

## 남은 범위와 다음 작업

DP11 전체는 미완료다. 독립 업무 평가셋/expected claims·source 기대조건·자동 평가, 과거 증적 조회 시 원문 저장소 재변조 탐지 전체 수용, SSE·독립 장시간 timeout, secret 참조·다중 모델·일반 제작자 기능은 후속이다. 현재 실행 시 원문 근거 검증과 조회 시 자료 ACL guard는 보존한다. 비교의 사용량/비용은 정산 상태·가격snapshot 확인 수준이며 호출별 토큰/금액 상세 비교와 전체 평가 내보내기/20건 초과 평가 pagination은 후속이다.

다음은 DP11 평가셋·승인 증적 계약을 보완하고 DP12 동적 배포 승인·게시를 연결한다. 개인 결과를 타인 승인자에게 제공하려면 정확한 version/run/result/profile/자료 권원에 기반한 별도 승인용 공유 계약을 먼저 구현한다. 기존 본인 전용 RPC를 승인자에게 광범위 공개하지 않는다. 실제 유료 제공자·Entra·기관 업무 품질 검증·운영 배포는 수행하지 않았다. SQL000~033 동결, 후속migration034 이상.
