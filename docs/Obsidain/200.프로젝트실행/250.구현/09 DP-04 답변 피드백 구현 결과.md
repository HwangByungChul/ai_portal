# DP-04 답변 피드백 구현 결과

## 사용자 기능

완료된 답변 아래에 도움 됐어요·아쉬워요, 선택적 의견, 평가 저장과 철회를 추가했다. 평가 변경·철회·재등록과 새로고침 시 본인의 저장 상태를 확인할 수 있다. 의견은 최대 1,000자이며 브라우저 영구 저장소에 저장하지 않는다.

평가는 실행별 한 행으로 관리한다. 현재 또는 직전 버전의 같은 내용 재전송은 중복 평가·감사를 만들지 않는다. 다른 변경과 충돌하면 최신 값을 다시 조회한다. 철회 시 의견을 비우고 활성 집계에서 제외하지만 버전과 최소 감사는 유지한다. 재등록 시 버전을 계속 증가시킨다.

## 권한과 관리자 집계

현재 본인이 읽을 수 있는 완료 답변만 평가한다. 미완료·실패·취소, 타 소유자·조직, 삭제된 대화와 원문 권한이 회수된 RAG 답변은 차단한다. 직접 DB 조회도 같은 소유자·답변 권한을 검사하며 직접 쓰기는 허용하지 않는다.

조직 관리 메뉴의 ‘답변 평가’에서 월·Agent별 활성 평가를 조회한다. 월은 활성 평가의 마지막 수정 시각(UTC) 기준이며 과거 상태의 보관 통계가 아니다. 실행 모드는 서버 설정에서 선택한다. feedback.summary_read를 현재 조직 관리 권한에 매핑했다. 글로벌 권한만으로 다른 조직 집계를 읽지 못한다.

Agent별 참여자가 3명 미만이면 건수를 숨긴다. 집계에 개인 질문·답변·제목·원문 의견·사용자·실행 식별자는 제공하지 않는다. 이 규칙은 완전한 익명화나 개인정보 마스킹 인증을 뜻하지 않는다.

## 데이터·감사·비용

022 변경 파일과 독립 피드백 모듈을 추가했고 기존 000~021 파일은 수정하지 않았다. 기존 실행·답변·봉인된 근거·비용 원장을 변경하지 않는다. 감사에는 평가 버전과 대상만 기록하며 의견 내용을 복사하지 않는다. 감사 저장 실패 시 평가 변경도 취소한다.

평가 API는 모델을 호출하지 않는다. 시연과 시험은 모의 응답을 사용했다. 폐기용 화면 시험 DB 초기화에는 새 평가 테이블을 명시적으로 추가했다. 기존 작업 DB를 초기화하지 않는다.
