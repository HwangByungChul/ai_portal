# DP11-03a 저장 버전 시험 실행

사용자 “네 진행 바랍니다” 승인으로 [[28 DP11 Agent Builder 프롬프트 RAG Playground 상세 개발 계획서]]의 Task2b/Task3 실행 기반을 개발했다. 본인 관리자 소유의 초안 시험이며 사용자 카탈로그 운영 실행·기관 수용·운영 배포와 구분한다. 전체 원본 F 기능 완료 인정으로 확대하지 않는다.

## 실제 변경

- immutable 자산 버전의 system/developer/user prompt를 단일 치환하고 실제 시험 메시지·profile hash·composition hash·자료 index scope를 봉인한다. SQL/Python 양쪽 변수 검증으로 재귀 치환을 막는다.
- migration032 builder_trials forced RLS. run task_kind=builder_trial와 실제 초안 버전 출처를 저장한다. 사용자 대화·메시지에서 시험 기록을 숨기며 현재 관리·본인·조직 권한을 요구한다. 고정 운영 Agent enabled/access/config gate도 그대로 사용한다.
- POST /admin/builder/assets/{asset}/versions/{version}/trials, GET /admin/builder/trials/{run}, POST 취소. 같은 client_send_id/같은 요청은 같은 run, 변경 요청409; 문서 회수는 replay/조회/worker/최종 저장도 차단한다. 문서 권한 회수 후에도 현재 관리·본인 권한이 있으면 취소 capability를 사용할 수 있다.
- 기존 admission locks/예산/동시성/분당 제한, worker epoch/lease, call reserve→confirmed dispatch→meter, 실행 실패·재시작 회수를 사용한다. admission에서 run+trial snapshot은 원자 생성하지만 실제 ledger reservation은 worker 호출 직전 기존 transaction에서 만든다. 비용·slot unknown 보존을 임의 해제하지 않는다.
- 일반 모델 시험은 AiGateway, RAG 검색 시험은 QueryGateway query embedding+실제 vector/graph 검색, RAG 생성은 typed fact 선택/원문 근거 검증을 재사용한다. 빈 저장 자료 scope는 검색 확대/제공자 호출 없이 부족근거 종료한다. RAG developer role도 보존한다.
- 최소 서버 model contract: default_general/default_rules_rag, 기존 gpt-4o-mini/text-embedding-3-small, 입력6000/출력1024/embedding4000 상한. price-20261004-v1은 동결 내부 추정이며 실제 최신 청구가격으로 표시하지 않는다. 임의 URL/다중모델/비밀 참조는 지원하지 않는다.
- React에 시험 실행·RAG 검색·상태/모의 제공자/정산 상태·결과·취소·같은 ID 접수 확인을 추가했다. 접수 불명/진행 동안 원본 편집·변수·다른 버전 저장을 잠근다. 취소 의도는 최초 stale revision409이면 최신 상태 확인 후 한 번 재시도한다.

[[30 DP11-03a 시험 정산 취소 권한 회수와 데이터 보존 검증]] 및 evidence/DP11-builder-trials에 증거를 저장했다. 서버 최신 고유 292사례 pass(여러 실행의 마지막 결과), 브라우저10사례 단일 실행 pass, user23/admin25 모듈 분리 빌드 pass. 신규 trial21사례 포함 corrected 단일 묶음62pass. 소유 local DB는 private600 backup 후 이전42표 전행 fingerprint와 SQL000~031/32개 checksum 보존, 43표/33migration/123security 함수, 새 trial 표0행 및 재적용 무변경 확인. Primary 합성 자산/run/제공자 호출 추가0, 세 서비스 복구/HTTP200.

모의 제공자만 사용했다. 실제 유료 API·품질/실제 Entra·기관 평가·운영 배포는 검증하지 않았다. 화면은 final 결과만 표시하고 현재 권한을 재검사하는 polling을 적용했다. 계획의 SSE 중간 출력은 이번에 구현하지 않았으며 이력에 보존한다. 과거 시험 목록/버전별 비교·평가셋/DP12 증적 승인·credentials 참조/다중모델·일반 제작자 역할은 미완료다. DP11 전체 완료로 표시하지 않는다.
