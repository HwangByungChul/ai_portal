## 4. A01 확인 중 수정과 당시 제한

1. 한글프로젝트내Unix소켓후보는108바이트였다. 실제통신경로를57바이트의전용private/tmp소유폴더로분리했다. 데이터는프로젝트안에유지한다. 소유marker/0700확인없이기존통신폴더를재사용하지않는다.

4. 이작업은초기관리용nativecluster다. 비우회web/index/meter·schema/FK/RLS·서버세션/로그인·브라우저화면은아직없다. mvp_bootstrap을웹런타임으로사용하지않는다. API는현재외부공개하지않는다.

## 9. A02 시험·실제 실행 증거

합성/평가9파일SHA불변, Q20 not_run유지,원본GraphRAG/BNK/무관제안자산보존. 이번도구의변경대상은전용55432 및A01회귀시험의임시55433이며기존5432는대상밖이다. 문서/Grant/Graph·실AI원장·브라우저/HTTP인증·전체V41은통과로집계하지않는다. baseline_commit은작업전이력이고tested_source_sha256이시험한실제파일을식별한다.
