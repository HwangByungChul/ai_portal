## 4. 확인 중 수정과 남은 제한

1. 한글프로젝트내Unix소켓후보는108바이트였다. 실제통신경로를57바이트의전용private/tmp소유폴더로분리했다. 데이터는프로젝트안에유지한다. 소유marker/0700확인없이기존통신폴더를재사용하지않는다.
2. 직접API재시작시험에서종료된TCP연결의TIME_WAIT로빈포트가점유된것처럼보였다. SO_REUSEADDR를적용한probe로실제listener와구분하고실행중포트거부/종료연결후재시작을둘다검증했다.
3. Starlette1.7.0 TestClient의httpx0.28.1사용에deprecation경고1개가있다. 실제19시험은통과했다. 경고를숨기거나자동으로httpx2를추가하지않으며추후호환성변경에서재검증한다.
4. 이작업은초기관리용nativecluster다. 비우회web/index/meter·schema/FK/RLS·서버세션/로그인·브라우저화면은아직없다. mvp_bootstrap을웹런타임으로사용하지않는다. API는현재외부공개하지않는다.
