# C05 문서·Job·공유·출처 화면 구현 결과

사용자·관리자 화면을 기존 C01~C04 실제 API에 연결했다. 모의 환경에서 등록→색인→정확한 버전 공유→규정 질문→근거·원문 다운로드→공유 회수 흐름을 검증했다. I250-4 기능 구현은 모의 검증 기준으로 완료했고, 전체 자료·답변 품질·Q20·통합 파일럿은 후속 단계다.

## 구현 범위

- 사용자 「내 자료」에서 현재 허용된 조직·개인·공유 문서를 조회하고 정확한 버전을 최대5개 선택한다. 일반 대화에는 문서 선택을 보내지 않고 규정 질문에만 적용한다.
- 관리자 「문서 관리」에서 TXT/Markdown 등록, 새 버전, 처리 Job·게시/정리 상태, 명시 재시도·삭제를 연결했다. 접수202를 완료로 표시하지 않으며, 불명확한 접수는 같은 요청ID와 내용으로 확인한다. needs_review를 자동 재실행하지 않는다.
- 공유는 특정 게시 버전에 발급·회수한다. v1 공유와 미공유v2를 구분하고 revision 충돌이면 최신 상태를 읽은 뒤 사용자의 명시 조작을 기다린다.
- 개인 문서의 관리권과 열람권을 구분한다. 현재 열람할 수 없는 제목을 숨긴다. 등록 화면의 개인 문서 소유자는 현재 등록 관리자이고 읽기 대상은 빈 목록이다. 다른 소유자·개별 읽기 대상 편집 화면은 제공하지 않는다. 서버의 기존 소유자/읽기 권한 강제는 유지하며 별도 소유자 자료도 시험했다.
- 규정 답변은 저장·근거 검증된 정본만 표시한다. 처리 중 RAG 초안은 표시하지 않고 검색·생성·저장 확인과 근거 부족을 구분한다. 각 질문은 독립 처리하며 과거 대화를 모델 문맥에 자동 포함하지 않는다.
- 근거의 제목·인용·행 위치를 일반 텍스트로 표시한다. 원문은 본인 실행의 고정 상대 경로와 현재 조직 헤더로 인증 다운로드하며 임시 Blob URL을 폐기한다. 민감한 문서·본문을 localStorage/sessionStorage에 저장하지 않는다.
- 조직 전환·늦은 응답·권한 회수 시 이전 내용을 지운다. 서버는 조회 시 즉시 현재 권한을 강제하고 화면은 수동 새로고침·가시화·포커스 및5초 간격으로 재확인한다. 실시간 push 회수를 구현한 것은 아니다.

## 검증 결과

| 범위 | 결과 | 실제 실행 시간 |
|---|---|---:|
| frontend 빌드 + 전체 브라우저 회귀 |60/60 통과·runner 오류0|192.78초|
| C05 관련 브라우저 |9/9 통과, 위60개에 포함|빌드 포함64.36초|
| 관련 서버 계약·등록·RAG |14/14 통과·실패/skip0|22.27초|
| 서버 전체 회귀 |이전 C04의737개 통과 기록 유지|이번 단계 재실행하지 않음|

backend 제품·SQL·common_core81개는 C04와 동일하다. 이번 변경은 frontend와 폐기용 브라우저 시험 도우미다. 시험 도우미는 primary 거부·DB 표식 검사를 유지하고 자기 소유 API/원문 저장소만 재시작·정리한다.

신규9개는 접수/게시 구분, exact v1 공유·v2 숨김·원문 다운로드·회수, 개인 제목 격리, 접수 응답 유실 복구, 불명 색인 예약 유지, 초안 비노출 및 실제 API 재시작 후 완료 답변 복원, 모바일/삭제, 공유 충돌, 조직 전환 후 늦은 응답 폐기를 확인했다. 재시작은 프로세스 변경 및 실제 health 준비를 확인했고 완료 조회에 추가 생성 호출이 없었다.

초기 시험의 개인 제목 선택자가 필터와 카드에 중복 매칭돼 카드로 범위를 한정했다. 재시작 시험은 프로세스 생성 후 실제 서버 준비까지 기다리도록 수정했다. 수정 후 관련9개와 전체60개를 다시 실행해 모두 통과했다.

## 보존·비용·제약

기존31테이블의 기존 열/행 지문,17개 migration, 보호32파일·이전65증거, 관련 없는 미추적74파일, GraphRAG 원본 HEAD와 선택9소스를 보존했다. 비밀 설정·키는 변경하지 않았다. 기본 환경은 mock/RAG비활성·새 corpus 미적재이며 Q20 원본은 not_run이다. 기존 일반 AI3회의 내부 추정0.19원·예약0·활성 슬롯0을 유지했다. 이번 유료 호출0회/추가비용0원이다.

종료 시 연결·임시 DB·개발 listener0, DB 정지 상태를 확인했다. 공개 증거에는 비밀값이나 자료 본문을 포함하지 않았다. 원격 push·배포는 수행하지 않았다.

현재 규칙 기반 GraphRAG의 의미 품질, 합성7버전 전체 실행, Q20, 실제 RAG 공급자 응답은 아직 평가하지 않았다. C05 화면 시험 통과를 전체 MVP 완료로 처리하지 않는다. 개인 실투입 공수는 미측정이며10월31일/주20h이상/기존80h·여유10h 기준을 유지한다.
