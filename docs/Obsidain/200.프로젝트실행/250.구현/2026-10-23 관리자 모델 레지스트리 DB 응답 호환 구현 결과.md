# 관리자 모델 레지스트리 DB 응답 호환 구현 결과

## 요청·결정
관리자 모델 레지스트리 페이지가 현재 `/admin/models`의 `{items:[...]}` 응답에서 레거시 인메모리 행과 DB 등록 행을 모두 표시하도록 수정했다. DB 행의 `display_name`, `active`, `price_input_usd`, `price_out_usd`, `context_window`, `max_output`을 사용하고, 누락된 값은 한국어 `정보 없음`으로 표시한다. `credential_ref`와 비밀 값은 frontend 타입에 넣거나 화면에 렌더링하지 않는다. PADMIN 경로 선택과 `tenantId` 헤더 전달은 유지한다.

## 변경 파일
- `src/frontend/packages/api-contract/src/types.ts`: DB 관리자 가격 정보를 포함한 DTO 타입 추가. 자격 증명 참조는 타입에 없다.
- `src/frontend/src/ModelAdminPage.tsx`: 레거시·DB 항목 정규화, 이름/상태/가격/한도/기능의 안전 표시 및 보안 안내 문구 조정. 사용자 노출 제목에서 DP-13 내부 코드를 제거했다. 관리·편집 컨트롤은 추가하지 않았다.
- `src/frontend/tests/dp13-acceptance.spec.ts`: 새 제목으로 기존 UI 기대값 수정, DB 응답 모킹 회귀 사례 추가. 응답의 `credential_ref`가 화면에 나오지 않는지, PADMIN의 `/admin/models` 요청과 tenant 헤더, 명칭·상태·가격·사양·누락값을 확인하도록 작성했다. 기존 레거시 모델 화면 확인과 공개 모델 API 테스트는 보존했다.

## 검증
- `npx tsc --noEmit` (bundled Node v24.19.0): 통과, 종료 코드 0.
- `git diff --check -- src/frontend/packages/api-contract/src/types.ts src/frontend/src/ModelAdminPage.tsx src/frontend/tests/dp13-acceptance.spec.ts 'docs/Obsidain/400.프로젝트관리/02 포털 UI UX 작업 기록.md'`: 통과, 종료 코드 0.
- Playwright 미실행: 현재 task의 frontend Playwright 설정은 fixture backend webServer를 새로 시작하도록 되어 있다. 직전 scoped run은 해당 프로세스가 시작 단계에서 종료(exit 1)했고 기본 출력 경로도 `EPERM`이었다. 기존 서비스 중지·교체 없이 반복 실행할 수 있는 상태가 확인되지 않아 브라우저 테스트를 시작하지 않았다.

## 미완료 범위
추가 DB fixture Playwright UI 케이스와 실제 PADMIN tenant 왕복은 작성했으나 실행하지 않았다. 실제 기관 수용 및 운영 배포를 검증한 것은 아니다. 이 변경은 관리자 화면 표시 호환성에 한정하며 모델 등록·수정·비활성화 기능은 포함하지 않는다.
