# I250-B06 Implementation Plan — 일반 대화 통합 검증

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. 기존 사용자 결정에 따라 현재 대화에서 순차 수행한다.

**Goal:** 승인된 B01~05 흐름을 장애·복구·현재 권한·실제 일반 질문 최대3회로 검증하고 C 단계 상세 계획으로 인계한다.

**Architecture:** 현재 단일 FastAPI/중앙 AI Gateway/ai_web·ai_meter 권한 경로를 사용한다. CLI는 보호된 HTTP run API만 호출한다. 별도 SDK 실행 경로를 만들지 않는다.

**Tech Stack:** 기존 FastAPI·PostgreSQL15·OpenAI SDK·httpx·pytest·React/Vite·Playwright. gpt-4o-mini/default/출력1024 고정.

## Global Constraints

- 키·비밀번호·질문·응답은 공개 로그/증거에 포함하지 않는다. 기존 설정과 비즈니스 원장·사용·예약을 보존한다.
- 실제 호출은 기존 대표 검증500원 안에서 최대3회, 내부 예약3×3.64=10.92원 이하. 자동 유료 재시도·모델 교체0. 이 금액은 공급사 청구액 보장이 아니다.
- 서버 key/auth/meter를 비공개 파일에서 읽고 mode=real은 자식 프로세스에만 적용한다. app.env의 mock 설정을 변경하지 않는다.
- 누락한 관리 조직 A의 real 예산만 최대500원 최초 준비한다. 기존 조직 예산·stop/latch·Agent를 자동 복원/증액하지 않는다.
- 비공개 단일 배치 journal을 영속화하고 재실행 시 추가 유료 호출을 거부한다. 실패·unknown·이용 거부이면 나머지 질문 발사를 멈춘다. 영수증 미수신은 예약을 보존한다.
- 원본 GraphRAG/원본 평가 Q20은 수정하지 않는다. C 검색/Job/Q20은 이 단계에서 완료로 표시하지 않는다.

- [x] `initialize_real_budget(db)`는 소유 fixture/관리 P-A→A를 확인한다. 기존 real 행은 그대로 반환하며 미존재 시 프로젝트 잠금/현재 잔여 범위에서 최대500원만 최초 삽입·audit한다.
- [x] key/meter/tokenizer/계정/조직/관리 범위/Agent/real 사용+예약/stop/latch/slot·500원 대표 여유를 점검한다. 예산 초기화 외 기존 보안·Agent·원장 reset0.

- [x] 결과 공개는 불투명 ID·모델·상태·시간·token·내부 추정/예약·안전 오류 코드만 허용한다.
