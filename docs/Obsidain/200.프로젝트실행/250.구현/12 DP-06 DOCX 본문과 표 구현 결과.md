## 화면에서 가능한 흐름

사용자 **내 자료** 또는 관리자 **문서 관리**에서 DOCX 선택→문서 접수→게시 확인→**AI 업무/규정 질의**에서 자료 선택→질문→**근거 보기**의 본문 문단 번호 또는 표/행/열 확인→**원문 내려받기**로 등록 바이트를 받는다. 삭제하면 즉시 접근을 차단하고 원본·canonical·색인을 정리한다. 기존 TXT/Markdown/PDF는 유지한다.

## 형식과 처리 계약

Transitional OOXML의 본문 문단과 중첩/병합 없는 표만 지원한다. 문단 번호는 빈 본문 문단을 포함해 계산하며 표/행/열은 실제 순서다. 빈 텍스트 단위는 canonical에서 생략하고 비어 있지 않은 단위를 두 줄바꿈으로 연결한다. 셀 내부 문단은 한 줄바꿈으로 연결한다. 페이지 번호는 추정하지 않는다.

원본128KB, 추출40,000자/128KB, ZIP 부품200개·개별1MB·총4MB·압축비100배, XML 깊이50·전체 부품 합산20,000노드, 비어 있지 않은 단위2,000개 이하. CPU2초·실행5초·50ms 간격 RSS512MB 초과 종료를 적용한다. RSS는 하드 메모리 상한이 아니며 순간 초과가 가능하다. 격리/감시 장애는 차단한다.

머리말/꼬리말/주석/각주/변경 추적/텍스트 상자/하이퍼링크/필드/자동 번호/숨김 텍스트/그림/중첩·병합 표와 미지원 부품은 거부한다. customXml 및 썸네일이 있는 일부 기본 Word 템플릿도 거부한다. 미지원 부품을 자동 제거하거나 본문을 조용히 누락하지 않는다. 일반 Word 문서 전체 호환성을 주장하지 않는다.

## 구현 연결

| 영역 | 결과 |
|---|---|
| 파서 | 메모리 ZIP+defusedxml, DTD/엔터티/외부 관계 차단, 정확한 타입·관계·부품 허용 목록 |
| 격리 | 기존 검증된 macOS 별도 프로세스 실행/자원 감시 재사용; 비밀 환경 미전달 |
| 접수 | 현재 권한·시도 제한·확정 재접수 조회 후 파싱; 최종 권한 재확인 후 저장 |
| 최소 수집 정책 | 제목+추출 본문/표 전체에 기존 document-ingest-v1 적용; DOCX 문서 속성은 개인정보 검사 범위 밖 |
| 저장 | canonical source와 DOCX original의 지문을 각각 보관; origin에 파서 버전·구조 위치 |

| 원본 | 현재 권한+두 SHA 확인 후 정확한 MIME/document.docx 반환 |
| 복구/정리 | 감사 실패의 비공개 파일 쌍은 같은 ID로 복구; 삭제/고아 정리 시 두 표현 제거 |
