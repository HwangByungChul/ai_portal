# MCP Tool Gateway 063-064 백업 클론 검증 결과

## 요청 및 결정
남은 MCP Tool Gateway 작업을 SDD 방식으로 계속 진행하고, 이전에 보류한 063/064 migration을 검증된 백업의 격리 clone에서 확인했다. 활성 fixture나 native 개발 DB에는 연결하거나 migration을 적용하지 않았다.

## 수행 내용
- 저장소의 PostgreSQL custom-format 백업을 확인하고 동일 백업으로 기준 DB와 검증 DB를 전용 disposable PostgreSQL 15 DevCluster(55433)에 각각 복원했다. 소유자와 ACL을 보존했다.
- 기준 migration head 055에서 검증 DB에 056–064를 순서대로 transaction 적용했다. 원본 migration 파일은 수정하지 않았다.
- 적용 후 migration source 000–064 총 65개의 checksum이 소스와 일치했고, 기존 테이블 75개의 행 수 및 기존 컬럼 기반 fingerprint가 기준 DB와 같았다. migration ledger에는 예상한 9개 항목만 추가됐다.
- 063 함수 소유자·SECURITY DEFINER·EXECUTE 권한을 확인하고 PUBLIC 실행 권한이 없음을 확인했다. 영향 받는 테이블의 ENABLE/FORCE RLS와 직접 권한 경계를 점검했다. 064 trigger 활성 및 소유권도 확인했다.
- 격리 transaction에서 빈 Registry 목록, 2개 Tool의 결정적 집계와 endpoint profile/latest revision/schema 반환, 교차 tenant 거부(A0403), 예약된 정적 Tool ID 세 건 거부(A0422)를 확인했다. 합성 변경은 전부 rollback했다.
- 두 clone DB와 소유한 DevCluster를 정리했고 55432/55433 listener가 없음을 확인했다.

## 실제 검증 결과
- 056–064 순차 적용: PASS (disposable clone만 사용)
- source checksum: 65/65 일치
- 기존 테이블: 75개 행 수 및 기존 컬럼 fingerprint 보존
- ACL/RLS/owner/trigger 검사: PASS
- 063 목록·tenant 거부 및 064 reserved ID 차단: PASS
- 합성 데이터: transaction rollback 확인
- native/활성 fixture DB 변경, 서비스 배포, 실제 IdP/외부 connector 호출: 없음

상세 실행 증거: `/private/tmp/mcp-gateway-063-064-clone-validation.md` (임시 검증 보고서).

## 미완료 범위 및 다음 작업
이번 검증은 additive schema migration의 clone 적합성만 확인한다. migration은 활성 fixture에 적용되지 않았고 배포·기관 수용을 뜻하지 않는다. 기관 IdP issuer/metadata·subject·MFA 기준과 실제 connector/Secret Manager 계약은 미정이며 verifier/production dispatch는 fail-closed 상태다.

다음 단계는 승인된 배포 창과 별도 백업·복구 절차가 마련된 후에만 활성 개발 환경 적용을 별도 요청·기록으로 수행하는 것이다. 그 전에는 063/064를 활성 DB에 적용하지 않는다. 이후 실제 IdP, MFA, connector, HTTP/auth/browser 흐름과 운영 수용을 별도 검증한다.
