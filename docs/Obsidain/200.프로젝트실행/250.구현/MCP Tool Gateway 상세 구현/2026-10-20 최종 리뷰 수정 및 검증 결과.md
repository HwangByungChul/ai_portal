# MCP Tool Gateway 최종 리뷰 수정 및 검증 결과

## 요청 및 결정
최종 통합 리뷰에서 확인한 Important 지적 2건과 Minor 1건을 수정하고, 앞선 Registry 집계/HMAC 환경값 지적을 포함해 전체 변경을 재검토했다. 소스 구현 범위는 승인됐으나 운영 적용·기관 수용 완료를 뜻하지 않는다.

## 반영한 변경
- 설정 검증 오류의 렌더링에서 입력값이 보이지 않도록 `hide_input_in_errors=True`를 적용했다.
- 미저장 Tool 모의 실행을 요청 단위 Gateway로 격리했다. 시뮬레이션은 영속 Registry를 변경하지 않고, 명시적 등록 동작만 저장한다.
- 기존 migration을 수정하지 않고 새 `064_mcp_tool_reserved_ids.sql`을 추가해 정적 Tool ID와 충돌하는 동적 등록을 차단한다.
- 승인 목록·상세의 위험 라벨을 일치시켜 동적 등록 검토와 고위험 Tool을 읽기 전용으로 표시하지 않게 했다.
- 앞선 `063_mcp_tool_registry_list_rpc.sql`은 한 tenant의 활성 동적 Tool 전체를 한 JSON 배열로 반환하며 저장소가 이를 호출한다.

## 검증 결과
- 지정 backend 회귀: 84 passed.
- 시뮬레이션 helper: 4 passed.
- 승인 라벨 테스트: 6 passed.
- 범위 지정 `git diff --check`: 통과.
- 관리자 빌드: 재실행에서 TypeScript, Vite, `verify-portal-builds.mjs admin` 모두 통과 (229 modules; admin boundary verified). 500KB 초과 JS chunk 경고 1건.
- 최종 독립 리뷰: 소스 범위 Spec PASS, Code Quality PASS, Critical/Important 잔여 없음.
- migration 056 SHA-256은 `3c6c2ea2d59d1936d8a08571719f6e043e7ec3ac021ad917353381698486ded0` 그대로다.

## 미완료 및 제한
- 063/064는 disposable backup clone에서 검증했으나 활성 fixture/native DB에는 적용하지 않았다. PostgreSQL 15 clone에서 checksum, 기존 데이터 fingerprint, ACL/RLS, 목록 RPC, reserved ID trigger 검증을 통과했다.
- 실제 IdP 고객 연동은 미정이며 verifier는 fail-closed 상태다.
- Vite 전체 build, 인증 브라우저 흐름, 실제 기관 connector/UAT 및 운영 배포는 확인하지 않았다.
- 테스트와 소스 리뷰는 합성/단위 수준이며 기관 수용이나 운영 준비 완료 증거가 아니다.

## 다음 작업
활성 개발 환경 적용은 승인된 배포 창, 백업 및 복구 절차를 별도로 준비한 후 별도 단계로 수행한다. 현재는 활성 DB migration 미적용을 유지한다. 기관 IdP/MFA·Secret Manager·connector 계약을 확정하기 전 production dispatch는 차단한다. 관리자 전체 build는 권한 허용 로컬 환경에서 완료했다. 500KB 초과 chunk 경고는 후속 성능 최적화 항목으로 남긴다.
