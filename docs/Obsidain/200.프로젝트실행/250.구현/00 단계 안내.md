# 250.구현

목표: 기능별 구현 결과와 코드·실행 방법·변경 이력을 연결한다.

현재 상태: **I250-A01~04 완료**. 인증·세션·DB/RLS·풀에 이어 조직 목록과 현재 조직 사용자 조회·활성 변경·역할 변경을 구현했다. 172개 시험과 실제 API 서버의 회수·충돌·감사 실패 증거를 확인했다. 다음은 A05 실제 로그인·조직·사용자 관리 화면이다. AI·전체A 통합 검증은 후속이다.

## 관리 항목

- 선행 입력 및 관련 요구사항
- 계획 산출물과 문서 ID
- 작성·검토·확정 상태
- 실제 구현·시험 증거 위치
- 미결정 사항 및 다음 단계 전달사항

6작업: I250-A01 환경·health/전용DB 도구 → A02 DB/RLS/풀 → A03 인증·세션 → A04 조직·관리 변경 → A05 실제 화면 → A06 재시작/통합 증거. 예상16~24h는 기존80h 안의 재배분 입력이며 실제 잔여시간이 아니다. A01착수예고는작성당시이력이다.
