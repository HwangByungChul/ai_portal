# B03 대화 접수 구현 계획

사용자가 B02 결과와 B03 상세 계획 보고 후 “네 진행 바릾”으로 진행을 승인했다. [[200.프로젝트실행/240.설계/04 API와 실행 상태 설계]] 및 [[200.프로젝트실행/250.구현/04 일반 대화와 중앙 AI 구현 결과#11. 다음 I250-B03 상세 작업 계획 — 예상3~5h]]을 구현한다. writing-plans의 체크 작업을 이 단계 폴더에서 관리하고 현재 대화에서 순차 수행한다.

**Goal:** 본인 대화·질문과 accepted 실행을 한 번만 저장하고 현재 권한으로 조회·취소한다.
**Architecture:** 기존 FastAPI/검증된 세션·조직 문맥과 PostgreSQL 고정 제어 함수를 사용한다. 동일 전송 ID의 UNIQUE와 identity→Agent→project→tenant→conversation/run 잠금, revision CAS, 동일 트랜잭션 감사를 연결한다.
**Tech Stack:** 기존 Python/FastAPI/psycopg/PostgreSQL/tiktoken; 새 의존성과 유료 AI 호출 0.

## 공통 제약
- 새 007만 추가하며 000~006, 기존 16 업무 테이블 행·원본·private app.env와 실제 비용을 보존한다.
- 질문 4000 Unicode codepoint/UTF-8 16KiB/JSON 전체 32KiB/입력 6000token; history는 현재 허용된 최근 완전 메시지 최대 6개다.
- 일반 Agent만 run을 접수하고 RAG·document_refs는 FEATURE_NOT_READY로 차단한다. provider·SSE·실행관리자는 B04다.
- 본인/현재 조직만 콘텐츠 조회 가능하다. 관리자 역할로 타인 대화 본문을 허용하지 않는다.
- 성공한 신규 접수만 user/tenant 10/min, 미종결 user1/tenant2/project4를 적용한다. 동일 접수 재전송은 한도·Agent 중지 후에도 현재 접근 권한을 검사하고 원래 결과를 반환한다.
- 미배정 예산은 안전한 준비 오류이며 기존 DB를 초기화해 숨기지 않는다. 접수는 reserve/dispatch/settle가 아니다.
- 목록 cursor는 조회종류·본인·현재 조직·대화 ID에 HMAC으로 묶고 created_at+UUID 순서를 유지한다.

## 파일과 인터페이스
- migrations/007_run_control.sql: current authority/RLS, owner read, atomic conversation/run/cancel, safe audit, capacity metadata/read/admission windows.
- app/conversations/repository.py: bound SQL + tenant_transaction, 서버 요청 hash, 로컬 tokenizer와 현재 이력 선택, safe SQL 오류 변환.
- app/conversations/routes.py: API07~13/strict body/상태 코드/조회 제한/현재 context.
- app/conversations/pagination.py: 표준 라이브러리 HMAC 서명 cursor, 문맥 바인딩·변조/다른 owner 거부.
- app/main.py/errors.py: router 등록/안전한 필드명과 코드만 추가. response의 선택 status_code는 기본 200을 유지한다.
- tests/test_conversations.py: 중복/격리/접수·취소/한도·토큰·cursor/rollback/실HTTP·재시작. support.py/test_migrations.py는 현재 단계의 catalog count/최소 권한 기대값을 갱신한다.
- 기존 콘텐츠 SELECT 금지였던 NOLOGIN policy executor는 새 owner-scope 고정 함수에 필요한 메시지·run snapshot만 읽는다. index/meter와 web의 private snapshot/hash 직접 읽기는 계속 거부한다. 동시성 판정만 내부 capacity scope에서 다른 run의 metadata를 세고 콘텐츠를 반환하지 않는다.
