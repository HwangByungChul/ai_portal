# 회의록 문서 날짜 및 품질 기록 구현 보고서

사용자가 요청한 ‘문서 자료 선택, 회의일·상대 날짜 처리, 실제 회의록 품질 보완’을 AGENT_03에 구현하고 있다. 나머지 9종 업무 Agent는 추후 확장 결정대로 유지한다. 계획은 [[34 회의록 문서 자료 날짜 처리 및 품질 평가 상세 개발 계획]], 관련 결정은 [[23 포털 UI UX 확정과 사이트 분리 검토]], 지속 기록은 [[02 포털 UI UX 작업 기록]]을 참조한다.

## 현재 완료 범위

- 메모 또는 최대 3건의 같은 조직 문서를 입력으로 사용하는 서버 계약을 구현했다. 정확한 문서 버전·원문 해시·현재 권한을 검증하고, 회의일과 입력을 실행 시점에 고정한다. 원문이 없거나 변경된 자료를 임의로 복원하지 않는다.
- 회의일 기준 오늘·내일·모레·N일 후·이번 주/다음 주 요일·명시 ISO 날짜를 계산한다. 기준일이 없거나 영업일·월말 등 지원하지 않는 표현, 상충하는 기한은 미확정 사유를 남긴다. 서버 실행 날짜로 대체하지 않는다.
- 결정·미정·액션의 원문 인용과 출처를 검사한다. 담당자 이름이 인용에 있더라도 실제 담당 배정의 의미가 맞는지는 사람이 검토한다.
- 완료된 본인 회의록에 정확성·누락·담당자·기한 평가와 의견을 추가하는 API를 구현했다. 기록은 덮어쓰지 않고 이력을 남긴다. 현재 결과 지문·버전 확인, 저장 충돌 처리, 동일 요청 재송신, 감사 로그와의 원자적 저장을 포함한다.
- 문서 회수와 실행·품질 저장이 동시에 발생하는 경우를 위해 문서 상태 잠금과 권한 재검사를 보완했다. 정상 Workflow 경로와 사용자 업무 경로에 같은 자료 검증을 적용한다.

## 검증과 한계

Task1 순수 계약·날짜·구조 평가 시험 76개와 독립 재검토가 통과했다. Task2 계약/이력 시험 103개, 실행 회귀 71개가 통과했다. 이후 변경은 좁은 문서·HTTP·child 경계 시험으로 확인했다. 독립 검토에서 문서 권한 동시성 문제(P1)를 발견했고, 수정 후 문서/migration 22개와 기존 실행 회귀 31개 시험 및 재검토가 통과했다. 시험 실행이 서로 겹치므로 숫자를 합산하지 않는다.

기존 SQL 000–050 51개 파일은 그대로 유지했다. 신규 파일은 `src/backend/migrations/051_meeting_context_quality.sql`이며 아직 실제 개발 DB에 적용하지 않았다. 코드·시험 파일과 정확한 명령, 초기 실패 및 수정, 결과는 [[task1-report]], [[task2-report]], [[task2-review-result]]와 `200.프로젝트실행/260.테스트/evidence/Meeting-context-20261015`에 보존했다.

합성 자료·구조화 테스트 provider의 통과는 실제 모델의 업무 품질 합격이 아니다. 유료 모델 호출은 0건이다. 실제 의미 품질 판정에는 승인된 업무 샘플·정답·제공자 설정과 사람의 검토가 필요하다. 기술 검사와 사람 평가를 분리한다.

## 진행 중과 다음 작업

사용자 화면의 문서 선택·회의일·근거·기한·품질 기록 연결 및 브라우저 수용을 진행 중이다. 이후 화면 독립 검토, 전체 기능 통합 검토, 실제 개발 DB의 검증된 백업 및 신규051 적용, 소유 서비스 3종 재구동, 최종 결과 기록 순으로 진행한다. 현재 서비스는 DB 시험을 위해 중지했으며 클러스터·계정·실제 데이터는 유지했다.

새 코드/출력 계약은 정상 Workflow 신규 제출과 타인 승인 절차를 요구한다. 기존 승인 snapshot이나 과거 결과를 소급 변경하지 않는다. 운영 배포·OCR/전사·다른9종 Agent는 이번 구현 범위 밖이다.


## 2026-10-15 화면 구현·재검토 완료와 재개 확인

문서 선택·회의일·기한/원문 근거·품질 기록 화면을 구현했다. 사용자 우선 기준인 결정사항·액션아이템 정확성을 먼저 표시하며, 평가 상태와 기한 상태를 한국어로 제공한다. 정확한 문서 식별자는 상세 펼침에 남긴다. 두 번째 페이지 자료 선택이 새로고침으로 해제되던 문제를 수정했고, 조회 실패 시 선택 보존과 실제 사용 불가 시 해제 안내를 검증했다.

사용자·관리자 최종 빌드, 마지막 집중 브라우저 시험 3개, 개별 화면 재검토가 통과했다. 앞선 집중 회귀 8개 및 동일 WF05의 확장 검증과 중복 합산하지 않는다. 실제 폐기형 DB/API와 HTTP stub 구분, 실패·수정·명령은 [[task3-report]]와 [[task3-review-result]]에 남겼다. 1440/1024/768 화면 증거를 보존했다.
