# 배포 관리 및 이력
본 문서는 생성형 AI 플랫폼의 형상관리 및 배포 이력을 체계적으로 관리하기 위한 문서입니다. 소스 코드의 원격 저장소 이행 현황, 버전별 배포 내역, 보안 점검 항목 및 후속 관리 기준을 명시합니다.

## 1. 소스 코드 저장소 정보
- **저장소 명**: ai_portal
- **원격지 URL**: `https://github.com/HwangByungChul/ai_portal.git`
- **기본 브랜치**: `main`
- **형상 관리 도구**: Git / GitHub

## 2. 배포 구성 요소
- **Frontend**: Vite 기반 분리 웹 포털 구조
  - `apps/user-web`: 일반 사용자 포털 (포트 5173)
  - `apps/admin-web`: 관리자 포털 (포트 5174)
  - `packages/api-contract`: 공통 API 인터페이스 및 타입 정의
  - `packages/ui`: 공통 UI 디자인 토큰 및 컴포넌트
- **Backend**: FastAPI 기반 비동기 API 서버 (`src/backend`, 포트 8000)
  - Agent Builder, Model Registry, Tool/Workflow 승인 제어
  - Guardrail 런타임 정책 및 이상 감지, 회의록/문서 워크플로우 처리
  - PostgreSQL 마이그레이션 스크립트 (000~051)
- **AI Core**: 공통 AI 파이프라인 및 RAG 엔진 (`src/common_core`)
- **환경 구성**: `config/environments/` (local, dev, tb, prd 명세) 및 제어 스크립트

## 3. 보안 및 형상 관리 정책
- **비밀 정보 제외**: `.env`, 서비스 계정 비밀번호, API 키, 비공개 접속 정보 문서는 Git 추적에서 제외(`gitignore` 적용)
- **독립 실행 검증**: 빌드 및 테스트 통과 상태의 유효 산출물만 원격 저장소에 배포
- **이력 불변성**: 주요 배포 시점마다 커밋 해시 및 변경 내역을 본 문서에 누적 기록
