# DP-04 답변 피드백 수용 기준

승인된 DP-04 계획과 AC-H08을 아래 기준으로 구체화한다. F013·F026의 전체 제안 범위 중 평가·비공개 의견과 최소 조직 집계를 구현한다. 관리자 원문 의견 조회·별점·담당자 분류·개선·종결은 후속이다.

| 기준 | 수용 결과 |
|---|---|
| H08-01 등록 | 본인의 현재 조회 가능한 완료 답변에 positive/negative 평가와 최대 1,000자 의견 등록 |
| H08-02 변경·재전송 | 동일 실행에 한 행만 유지하고 버전 증가, 같은 내용의 현재/직전 버전 재전송은 안전 응답 |
| H08-03 철회·재등록 | 철회 후 조회는 비활성·의견 없음이며 재등록 버전은 계속 증가 |
| H08-04 권한·상태 | 미완료·실패·취소·타 사용자·타 조직·삭제·현재 RAG 자료 권한 회수를 차단 |
| H08-05 원장·감사 | 평가로 모델 재호출·비용 변경 없음, 최소 감사 저장 실패 시 평가도 취소 |
| H08-06 조직 집계 | feedback.summary_read에 해당하는 현재 조직 관리자만 조회, 현재 모드·월·Agent 분리 |
| H08-07 개인정보 | 관리자 집계에 사용자·실행·질문·답변·제목·원문 의견 없음, Agent별 참여자 3명 미만은 건수 숨김 |
| H08-08 화면 | 평가·의견 저장·변경·철회·새로고침·모바일·조직 전환·충돌·권한 회수 확인 |

기존 Q20 전체 검증, 10개 조직 부하, HA·DR와 기관 검수 완료로 확대하지 않는다.
