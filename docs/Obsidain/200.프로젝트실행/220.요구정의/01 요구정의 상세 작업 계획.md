## 공통 작성 규칙

요구 ID는 UP-001(사용자), AP-001(관리자), CP-001(공통 기능), NFR-001(비기능) 형식으로 중복 없이 부여한다. 역할 ID는 ACT-USER·ACT-TADMIN·ACT-PADMIN으로 정의한다. 이는 문서 식별자이며 코드 권한 이름을 선확정하지 않는다.

각 요구는 **ID·명칭·근거·액터·우선순위·선행 조건·입력·정상 결과·거부/실패 결과·접근 범위·수용 기준·연결 검증 ID**를 갖는다. 검증 ID는 V-001부터 부여하고 실제 시험 결과는 260/280에서 기록한다.

우선순위는 필수/편의/후속으로 구분한다. 조직 격리·개인 권한·허용 근거·대화/작업 지속 저장·공통 모델 호출·한도/중지 차단은 필수다. 편의 기능은 목표 일정에 맞춰 축소할 수 있다.

근거는 사용자 결정, 승인 계획, 210 결정, 확인한 원 RFP/화면으로 구분한다. 원 RFP 조항 번호는 해당 원문을 확인했을 때만 기재한다. 기존 시연 화면이 있다고 구현 완료 또는 필수 요구라고 판단하지 않는다. 이번 220은 전체 원 RFP 대응표 완성 작업으로 확대하지 않는다.
