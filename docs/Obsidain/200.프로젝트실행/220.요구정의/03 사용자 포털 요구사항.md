# 사용자 포털 요구사항

## 작성 상태와 기준

R220-03 문서 작성 및 자체 점검을 완료했다. 요구사항 초안이며 앱 화면 구현·API 호출·실제 시험 결과가 아니다. 상세 권한과 요구의 최종 검토는 R220-07에 묶어서 수행한다. 210 종합 검토 대기 상태를 소급 확정하지 않는다.

기준: [[100.프로젝트계획/03 프로젝트계획서]], [[200.프로젝트실행/210.아키텍처정의/04 아키텍처 검토 결과와 후속 전달]], [[200.프로젝트실행/220.요구정의/02 액터와 권한 정의서]]. 원 RFP 조항별 대응이나 기존 시연 화면과의 일대일 분석은 아직 수행하지 않았다.

## 업무 흐름과 공통 조건

로그인 → 허용 조직 선택 → 허용 Agent 선택 → 질문 전송 → 진행 상태 → 일반 또는 RAG 답변/근거 → 본인 기록 저장/재조회로 이어진다. 사용자 화면에 현재 조직과 Agent를 명시한다. 조직 전환 시 이전 조직 데이터와 늦게 도착한 응답을 새 조직 화면에 섞지 않는다.

모든 요구의 액터는 ACT-USER다. 관리자가 이 흐름을 사용할 때도 본인 사용자 권한과 문서 ACL을 적용한다. 아래 12개 요구는 필수이며 세부 화면 장식·검색 편의·내보내기·모델 선택·사용자 파일 업로드·대화 공유/조직 간 이동은 후속이다. 일반/RAG 답변은 선정된 저비용 모델의 공통 호출을 사용하며 다중 모델 선택 기능을 추가하지 않는다.

## UP-001 로그인·로그아웃

- **근거:** 100 승인 MVP 범위, 210 IN-01, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 활성 계정, 로그인 전 또는 유효 세션.
- **입력:** 로그인 정보 또는 로그아웃 요청.
- **정상 결과:** 본인의 최소 정보와 허용 조직을 표시한다. 로그아웃 후 기존 화면 데이터와 세션 접근을 종료한다.
- **거부/실패 결과:** 인증 실패/비활성 계정은 업무 화면에 진입하지 못한다. 로그아웃한 인증정보로 신규 업무 요청을 허용하지 않는다.
- **접근 범위:** 본인 계정과 최소 소속 정보.
- **수용 기준·V-001:** 활성 계정 로그인→허용 조직만 표시; 잘못된 로그인→업무 데이터 미반환; 로그아웃→이전 인증정보의 새 요청 거부. 비밀번호/키는 화면 오류에 노출하지 않는다.

## UP-002 조직 선택·전환

- **근거:** 100 승인 MVP 범위, 210 IN-01·IN-03·IN-12, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 인증 완료, 활성 소속 1개 이상.
- **입력:** 허용 조직 선택 또는 전환.
- **정상 결과:** 현재 조직을 명시하고 Agent/대화/근거 표시를 해당 조직으로 갱신한다. 선택 전 조직 업무를 실행하지 않는다.
- **거부/실패 결과:** 미소속 조직 ID는 거부한다. 전환 실패 시 다른 조직 화면을 섞지 않고 서버가 확인한 조직 상태로 안내한다.
- **접근 범위:** 한 요청의 활성 조직, 기존 자원 소유 조직은 유지.
- **수용 기준·V-002:** A→B 전환 시 A 대화/근거/질문 입력을 B 화면에서 제거하고 늦게 도착한 A 응답을 B에 표시하지 않는다. A 대화 ID를 B 문맥으로 요청하면 거부한다.

## UP-003 허용 Agent 목록·선택

- **근거:** 100 승인 MVP 범위, 210 IN-02, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 활성 조직 확인.
- **입력:** Agent 목록 조회 및 선택.
- **정상 결과:** 허용된 일반 질의/RAG Agent의 이름·용도·실행 상태를 표시한다. 선택한 Agent를 질문 화면에 명시한다.
- **거부/실패 결과:** 무권한 Agent는 목록/설정 내용을 노출하지 않는다. 직접 ID 실행도 검사하며 중지 Agent는 실행 불가로 표시한다.
- **접근 범위:** 현재 조직의 허용 Agent.
- **수용 기준·V-003:** A에 허용되지 않은 Agent ID 실행은 거부; 중지 Agent는 실행 차단; 선택 변경은 기존 대화의 Agent/조직 소유 정보를 덮어쓰지 않는다.

## UP-004 질문 입력·전송

- **근거:** 100 승인 MVP 범위, 210 IN-02, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 활성 사용자/조직, 허용 실행 Agent.
- **입력:** 질문 텍스트와 선택 대화/Agent.
- **정상 결과:** 입력 조건 확인 후 실행 식별자와 진행 상태를 반환한다. 사용자가 새 대화 또는 본인 기존 대화에서 질문할 수 있다.
- **거부/실패 결과:** 공백·설정된 입력 상한 초과·타인 대화 ID는 실행 전에 거부한다. 무권한 요청은 모델을 호출하지 않는다.
- **접근 범위:** 본인/현재 조직의 질문·대화.
- **수용 기준·V-004:** 공백/상한 초과 입력에서 실행/모델 호출 없음; 전송 버튼 반복 클릭과 통신 재전송으로 동일 전송의 실행/과금이 중복되지 않는다. 식별 방식/길이값은 240에서 정의한다.

## UP-005 일반 질의 답변

- **근거:** 100 승인 MVP 범위, 210 IN-02·IN-03·IN-10, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 일반 질의 Agent 실행 허가.
- **입력:** 질문과 허용 대화 문맥.
- **정상 결과:** 공통 AI 경로의 실제 답변을 표시하고 실행 상태와 연결해 저장한다. 문서 검색을 수행한 RAG 답변과 구분한다.
- **거부/실패 결과:** 공급자 오류를 성공 답변으로 표시하지 않는다. 다른 조직 대화/문서로 내용을 보충하지 않는다.
- **접근 범위:** 현재 조직의 본인 대화 문맥.
- **수용 기준·V-005:** 일반 답변에 플랫폼 문서를 검색/인용한 것처럼 근거 목록을 꾸미지 않는다. 실제 모델 미연결 시 모의 응답 표시를 구분하고 실제 검증 완료로 기록하지 않는다.

## UP-006 문서 기반 RAG 답변

- **근거:** 100 승인 MVP 범위, 210 IN-02·IN-04·IN-11, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** RAG Agent 실행 허가, 접근 가능한 색인 자료.
- **입력:** 질문과 허용 대화 문맥.
- **정상 결과:** 허용 조직/개인/공유 버전에서 검색한 자료로 답변하고 주장·관계에 맞는 원문 근거를 연결한다.
- **거부/실패 결과:** 권한 범위를 넓혀 답변을 보충하지 않는다. 검색 실패와 근거 부족을 일반 성공 답변으로 처리하지 않는다.
- **접근 범위:** 현재 조직에 허용된 문서/청크/관계/근거.
- **수용 기준·V-006:** 관계 R1 질문에는 R1에 연결된 허용 근거를 사용하며 무관한 R2 근거나 B 비공유 자료가 본문/근거 목록에 포함되지 않는다.

## UP-007 실행 진행·실패 상태

- **근거:** 100 승인 MVP 범위, 210 IN-02·IN-03·IN-12, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 본인 실행 접근 권한.
- **입력:** 질문 실행 또는 본인 실행 상태 조회.
- **정상 결과:** 진행중·완료·실패·취소 요청/종결·거부를 구분하고 재조회 시 서버 저장 상태를 표시한다. 정확한 상태 명칭/전이는 240에서 정한다.
- **거부/실패 결과:** 연결 종료/화면 닫힘을 완료 또는 무료 처리로 단정하지 않는다. 저장 실패는 기록 저장 실패로 알리고 미저장 응답을 저장 완료로 표시하지 않는다.
- **접근 범위:** 본인/현재 조직 실행, 오류 정보 최소 범위.
- **수용 기준·V-007:** 응답 중 오류가 나면 부분 내용을 미완성으로 표시한다. 재연결/재시작 후 서버 상태를 확인할 수 있다. 공급자 비밀/타 조직 자원 정보는 오류에 노출하지 않는다.

## UP-008 본인 실행 취소 요청

- **근거:** 100 승인 MVP 범위, 210 IN-02·IN-03, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 본인/현재 조직의 진행중 실행.
- **입력:** 취소 요청과 실행 식별자.
- **정상 결과:** 취소 요청 접수와 실제 종결 상태를 구분해 표시한다. 완료 후 취소 요청은 완료 사실을 유지한다.
- **거부/실패 결과:** 타인/다른 조직 실행 취소는 거부한다. 요청 접수만으로 공급자 호출 즉시 종료·비용 0을 표시하지 않는다.
- **접근 범위:** 본인/현재 조직 실행.
- **수용 기준·V-008:** 진행중 취소→접수/최종 상태 재조회 가능; 완료와 취소의 경합에서 하나의 실제 종결 결과 유지. 표시와 취소 전파/usage 상세는 240 공통 실행 계약에 연결한다.

## UP-009 근거 목록·원문 조회

- **근거:** 100 승인 MVP 범위, 210 IN-04·IN-07·IN-11, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 본인 답변과 현재 문서 접근 권한.
- **입력:** 근거 선택 또는 원문/링크 요청.
- **정상 결과:** 허용 근거의 문서명·버전·위치·인용 내용을 표시하고 대응 원문을 조회한다. 관계별 근거 연결을 유지한다.
- **거부/실패 결과:** 삭제/공유 회수/ACL 변경 후 근거 링크·미리보기 접근을 거부한다. 무권한 문서의 제목/본문을 오류에 노출하지 않는다.
- **접근 범위:** 본인 답변이더라도 근거 문서는 현재 ACL 별도 검사.
- **수용 기준·V-009:** A가 승인 공유 버전만 조회; 회수 후 같은 과거 답변 링크를 클릭해도 원문/미리보기 미반환. 미확인 일반 링크를 서버 권한 검사를 건너뛰는 파일 경로로 제공하지 않는다.

## UP-010 본인 대화 저장·재조회

- **근거:** 100 승인 MVP 범위, 210 IN-03·IN-12, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 본인/현재 조직 대화 접근 권한.
- **입력:** 본인 대화 목록/상세 요청 또는 실행 결과.
- **정상 결과:** 질문·답변·Agent·조직·실행 상태·근거 연결을 저장하고 재로그인/서버 재시작 후 본인 기록을 조회한다.
- **거부/실패 결과:** 타인/다른 조직 대화 ID·목록 접근을 거부한다. 기록 저장 실패를 정상 저장으로 표시하지 않는다.
- **접근 범위:** 본인/현재 조직, 관리자 자동 내용 열람 없음.
- **수용 기준·V-010:** A의 U1 대화는 A의 U2나 관리자 역할만으로 조회할 수 없다. 재시작 후 완료/실패 상태와 기록이 유지된다. 과거 근거 링크는 UP-009의 현재 권한을 적용한다.

## UP-011 중지·한도·무권한 안내

- **근거:** 100 승인 MVP 범위, 210 IN-02·IN-08·IN-09·IN-10, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** 질문 또는 업무 요청.
- **입력:** Agent/대화 요청과 현재 사용자/조직.
- **정상 결과:** Agent 중지, 호출 한도 초과, 접근 불가, 인증 만료를 구분 가능한 안내로 표시한다. 최신 허용 상태 확인 후에만 새 실행한다.
- **거부/실패 결과:** 허가 거부 요청에서 모델 호출을 실행하지 않는다. 다른 Agent/모델/조직으로 자동 우회하지 않는다.
- **접근 범위:** 본인 상태와 현재 조직의 최소 안내 정보.
- **수용 기준·V-011:** 역할/소속 회수 후 열린 화면의 새 요청 거부; 중지/한도 거부는 실제 모델 미호출. 전체 프로젝트 잔여 예산이나 타 조직 설정은 일반 사용자에게 노출하지 않는다.

## UP-012 근거 부족 안내

- **근거:** 100 승인 MVP 범위, 210 IN-04·IN-11, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER · 필수.
- **선행 조건:** RAG 요청에 허용 근거가 없거나 답변을 뒷받침하기 부족.
- **입력:** 검색 결과 및 질문.
- **정상 결과:** 근거 부족/답변 보류를 표시하고 확인 가능한 범위만 제공한다. 문서 등록/처리 상태 확인 또는 질문 구체화를 안내한다.
- **거부/실패 결과:** 권한 밖 문서의 존재/이름을 힌트로 공개하거나, 무근거 단정을 근거 있는 답변으로 표시하지 않는다.
- **접근 범위:** 현재 허용 자료 범위, 자료 없음과 내부 검색 오류 구분.
- **수용 기준·V-012:** 정답 근거가 B 비공유 문서에만 있는 A 질문→B 자료/제목 비노출, 근거 부족 또는 자원 접근 거부로 처리. 검색 시스템 오류는 근거 부족으로 숨기지 않고 실패 상태로 기록한다.

## 240 상세 설계 전달

세션/로그아웃 계약, 조직 전환과 요청/스트림의 조직 식별·이전 화면 정리, Agent/대화 연결, 입력 길이·동시 실행·동일 전송 식별, 실행/취소 종결 상태, 저장 실패 처리, 근거/문서 버전 및 현재 ACL, 과거 대화 인용 본문 표시를 240에서 설계한다. 이미 전송된 내용의 외부 복사까지 회수할 수 있다고 주장하지 않는다. 실패 재전송은 자동 무제한 호출 대신 상태 확인과 새 실행 여부를 명시한다.
