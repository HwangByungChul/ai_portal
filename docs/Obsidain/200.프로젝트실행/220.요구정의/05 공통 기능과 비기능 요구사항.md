# 공통 기능과 비기능 요구사항

## 상태와 기준

R220-05 문서 초안 작성·자체 점검을 완료했다. 서버 기능 10개와 횡단 품질 요구 6개를 정의하며 실제 코드/API/DB·모델 호출·시험 결과는 아니다. 210 종합/220 최종 검토 상태는 유지하고 전체 요구 검토는 R220-07에서 수행한다.

## 모듈 책임과 범위

API 공통 진입은 인증 문맥·요청 추적/HTTP 제한, 업무 서비스는 자원 권한/대화/문서/실행, AI 공통 호출은 제공자 요청/응답과 호출 상태, Usage/Quota는 단일 원장/허가/예약/정산을 담당한다. GraphRAG는 허용 검색/관계/근거를 조립하고 저장소 어댑터에서도 조직/ACL을 강제한다. Job은 승인된 주체/조직과 자체 세션을 사용한다. 분리된 책임은 하나의 FastAPI 배포 안에서 구현한다.

기본 생성/임베딩 모델과 10월30,000원 상한을 유지한다. 기관 과금·동적 모델 라우팅·Gateway 제품·물리 테넌트 격리·HA/SSO는 필수 범위에 추가하지 않는다. 모든 아래 요구는 필수 초안이며 API 경로·SQL·제한값·상태 전이는 240 설계에 전달한다.

## CP-001 인증·활성 소속·요청 조직 문맥

- **근거·연결:** 100/210 기준과 UP-001/002/011, AP-001~003, 220 액터/권한 정의.
- **액터·우선순위:** ACT-USER / ACT-TADMIN / ACT-PADMIN, 확인된 Job 주체 · 필수.
- **선행 조건:** 인증/소속을 확인해야 하는 업무 요청 또는 Job 실행.
- **입력/검증 상황:** 인증정보·선택 조직·자원/Job 식별자.
- **정상 결과:** 서버가 활성 사용자/소속/역할과 한 요청의 조직을 확인하고 업무·DB·AI·Job 경계에 전달한다. 로그인 전 최소 계정/소속 조회를 조직 자료의 전역 조회로 확대하지 않는다.
- **거부/실패 결과:** 문맥 누락·인증 만료·소속 회수·변조 조직 선택을 거부한다. 이전 세션/Job 승인만으로 신규 무권한 호출을 허용하지 않는다.
- **접근/적용 범위:** 단일 요청의 검증된 조직/주체, Job 자체 세션.
- **수용 기준·V-026:** 소속 회수 후 이전 토큰 새 요청 거부; 조직 문맥 없는 업무 조회/쓰기 거부; Job 재시도/산출물 공개 직전 현재 주체·자료 권한 확인.

## CP-002 자원·개인·공유 접근 강제

- **근거·연결:** 100/210 기준과 UP-003/006/009/010, AP-004/007/008, 220 액터/권한 정의.
- **액터·우선순위:** 모든 업무 액터 및 저장소/Job 주체 · 필수.
- **선행 조건:** CP-001의 검증된 문맥.
- **입력/검증 상황:** 문서/청크/개체/관계/근거/대화/Agent/파일/Job 조회·쓰기.
- **정상 결과:** 조직 조건과 자원 ACL을 서비스/저장소에서 적용하고, 공유는 원 소유 조직 문서 특정 버전의 유효 Grant로 허용한다. 조직 런타임 데이터에는 RLS를 적용한다.
- **거부/실패 결과:** 타 조직·타인 개인 자료·수신 자료 변경/재공유·누락 ACL은 거부한다. 전역 관리자라는 이유로 RLS를 우회하지 않는다.
- **접근/적용 범위:** 현재 조직과 개인/명시 공유 범위, 런타임 DB 역할.
- **수용 기준·V-027:** Graph seed·관계·근거 링크·벡터 검색·다운로드에서 같은 허용 범위 적용; 런타임 DB 역할에서 문맥 누락/타 조직 조회와 쓰기 차단; 관리자 자동 개인 본문 열람 불가.

## CP-003 요청 추적·입력 제한·동일 전송 식별

- **근거·연결:** 100/210 기준과 UP-004/007, AP-004/006, 220 액터/권한 정의.
- **액터·우선순위:** 모든 API 액터 · 필수.
- **선행 조건:** 검증 가능한 업무 요청.
- **입력/검증 상황:** 질문/파일·요청 식별 정보·실행/Job 식별자.
- **정상 결과:** 요청 ID로 업무 실행/Job/모델 호출 기록을 연결한다. 질문/파일 크기·HTTP 요청 빈도·동시 실행을 설정값으로 제한하고 동일 전송의 중복 실행을 방지한다.
- **거부/실패 결과:** 공백·지원 외 형식·상한 초과 요청은 유료 호출 전에 거부한다. 실패/재전송을 무조건 새 유료 실행으로 처리하지 않는다.
- **접근/적용 범위:** 현재 조직/주체 요청과 실행, HTTP 제한과 토큰 한도는 구분.
- **수용 기준·V-028:** 동일 질문 내용만으로 별개 정상 요청을 합치지 않으며 같은 전송 ID 반복에서 중복 실행/usage 방지; 제한 거부→모델 호출 없음. 정확한 제한값/식별 계약은 240에서 정의한다.

## CP-004 생성·임베딩 공통 AI 호출

- **근거·연결:** 100/210 기준과 UP-005/006, AP-006/009/010/013, 220 액터/권한 정의.
- **액터·우선순위:** 실행/색인 서비스와 주입된 GraphRAG 호출 계약 · 필수.
- **선행 조건:** 현재 권한·Agent 상태·공통 중지·한도 허가.
- **입력/검증 상황:** 용도·모델 설정·Payload·실행/조직/주체 문맥.
- **정상 결과:** 생성은 gpt-4o-mini, 문서/질의 임베딩은 text-embedding-3-small을 서버 공통 호출로 처리한다. 용도·실제 모델/버전·응답/usage 상태를 기록한다.
- **거부/실패 결과:** 허가 실패·중지/한도 초과·설정 오류는 호출 전 차단한다. 업무/GraphRAG가 직접 키로 호출하거나 더 비싼 모델/다른 조직으로 자동 폴백하지 않는다.
- **접근/적용 범위:** 질의 생성·문서/질의 임베딩, 향후 추출도 동일 경로.
- **수용 기준·V-029:** 실제 모델 대표 시험에서 일반/RAG/문서 및 질의 임베딩 호출이 같은 허가/기록 경로를 사용함을 확인; 반복 시험의 모의 실행은 실제 호출과 구분. 키는 서버 설정에만 둔다.

## CP-005 단일 사용량 원장·한도 예약/정산

- **근거·연결:** 100/210 기준과 UP-011, AP-011~013, 220 액터/권한 정의.
- **액터·우선순위:** Usage/Quota 시스템 주체, 허용 운영 집계 액터 · 필수.
- **선행 조건:** 실행/호출 식별과 현재 단가·정책.
- **입력/검증 상황:** 조직·용도·예상 사용량·확정 usage·실패/불명 결과.
- **정상 결과:** Usage/Quota 하나가 호출 허가/예약/확정/불명 상태를 소유하고 프로젝트/조직 한도를 함께 검사한다. 생성·임베딩/재시도 모두 기록한다.
- **거부/실패 결과:** 원장 중복·관리자 수동 수정·불명 usage 0 처리·한도 변경으로 기존 사용량 삭제를 허용하지 않는다. 예약/원장 쓰기 실패 시 신규 유료 호출을 허가하지 않는다.
- **접근/적용 범위:** 본인/조직 운영/프로젝트 운영 구분, 프로젝트 상한 30,000원.
- **수용 기준·V-030:** 동시 요청이 동일 잔여 한도를 중복 사용하지 못함; timeout 불명은 보수적으로 유지; 호출별 실제/추정·통화/환산 기준 구분과 운영 대조 가능. 고급 과금/실시간 환율 동기화 없이 기본 고정 정책으로 구현한다.

## CP-006 실행·취소·재시도·중지 상태

- **근거·연결:** 100/210 기준과 UP-007/008/011, AP-006/010/013, 220 액터/권한 정의.
- **액터·우선순위:** 본인 실행 사용자, 허용 운영 관리자, 실행/Job 주체 · 필수.
- **선행 조건:** 저장된 실행/호출/Job과 현재 권한.
- **입력/검증 상황:** 실행 시작·진행·응답·오류·취소·timeout·중지/재시도 요청.
- **정상 결과:** 진행/완료/실패/취소 요청/실제 종결을 구분해 지속 저장한다. 중지는 신규 유료 실행·재시도를 차단하고 재개도 권한/한도를 재검사한다.
- **거부/실패 결과:** 부분 응답·연결 종료·취소 접수만으로 정상 완료/무료를 표시하지 않는다. 무제한 자동 재시도, 완료 요청 중복 정산, 무권한 타인 실행 취소를 막는다.
- **접근/적용 범위:** 본인 또는 허용 조직 운영 실행/Job, 이미 발생한 usage 유지.
- **수용 기준·V-031:** 완료/취소 경합에서 일관된 실제 종결 결과; Agent/공통 중지 이후 신규 호출 없음; 공급자 응답 불명과 실패를 구분. 제한 횟수·timeout·중지 적용 시점·기진행 호출 전파는 240에서 설계한다.

## CP-007 문서 색인·버전·재처리

- **근거·연결:** 100/210 기준과 AP-004~006, UP-006, 220 액터/권한 정의.
- **액터·우선순위:** 허용 문서 관리자·승인 범위 Job 주체 · 필수.
- **선행 조건:** 지원 TXT/Markdown 등록, 현재 자료 권한·한도.
- **입력/검증 상황:** 문서 버전/해시·파싱/청킹·규칙 기반 관계 추출·임베딩/저장 결과.
- **정상 결과:** 단계 상태와 문서/색인/모델 버전을 기록하고 필요한 Graph/벡터/근거 산출물이 검증된 경우만 검색 가능한 완료로 표시한다. 변경 없는 유효 색인은 재사용한다.
- **거부/실패 결과:** 파싱/임베딩/Graph 저장·근거 검증 실패는 실제 실패 단계로 남긴다. 부분 색인이나 모의 그래프를 실제 완료로 표시하지 않는다.
- **접근/적용 범위:** 문서 소유 조직·개인 ACL, Job 자체 조직 문맥/세션.
- **수용 기준·V-032:** 합성 문서 5~10개 처리→허용 청크/관계/근거 검색; 같은 문서/색인 버전의 재요청에 불필요한 재임베딩 없음; 실패 재처리에서 다른 조직/버전 산출물 혼입 없음.

## CP-008 GraphRAG 검색·관계별 근거·보류

- **근거·연결:** 100/210 기준과 UP-006/009/012, AP-005, 220 액터/권한 정의.
- **액터·우선순위:** 허용 RAG 실행/검색 서비스 · 필수.
- **선행 조건:** 허용 색인 자료와 현재 ACL.
- **입력/검증 상황:** 질문·허용 검색 범위·관계/원문 근거.
- **정상 결과:** 권한 범위 안에서 벡터/Graph 검색과 관계별 근거를 조립해 답변에 전달한다. 자료 없음·근거 부족·권한 거부·검색 오류를 구별한다.
- **거부/실패 결과:** 다른 조직/임의 문서로 폴백하거나 관계 R1에 무관한 R2 근거를 연결하지 않는다. 내부 검색 오류를 근거 부족으로 숨기지 않는다.

## 240 설계 전달과 현재 판정 범위

상세 설계에서 확정할 값/계약은 인증/소속 재검사, 자원 ACL/RLS/파일/캐시 강제, 요청/전송 식별, 호출 길이·HTTP/동시 실행 한도, timeout/재시도·취소/중지·Job 상태 전이, usage 예약/확정/불명·원화 환산/운영 대조, 색인 버전/실패 재처리, 삭제/공유 회수의 차단·물리 정리·과거 인용 본문, 최소 활동 기록 접근, 설치/초기화와 성능 환경/목표값이다.

위 전달은 요구 누락을 숨기는 미정 항목이 아니라 단계별 책임 구분이다. 특히 NFR-005의 성능 수치 판정은 240에서 승인된 목표와 실측 결과가 있어야 하며 이 문서만으로 성능 통과를 주장하지 않는다.

## 자체 점검 결과

CP-001~010과 NFR-001~006, V-026~041의 중복/누락을 확인했다. UP12·AP13과 본 문서16을 합쳐 현재 요구 초안은 41개다. 각 공통 요구에 근거·액터·입력/조건·정상/실패·범위·수용 기준을 작성했다. 단일 원장 책임·관리자 ACL·Job 권한·중지/취소·삭제/회수·모의/실제 구분을 포털 요구와 대조했다. 기관 성능/보안 인증 또는 구현/시험 완료를 주장하지 않는다.
