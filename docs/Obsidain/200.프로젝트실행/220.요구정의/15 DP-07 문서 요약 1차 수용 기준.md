# DP-07 문서 요약 1차 수용 기준

## 요청과 범위

사용자가 PPTX·OCR을 추후 진행하고 다음 작업을 요청했다. 다음 묶음은 DP-07이다. 기존 DP-05와 DP-06의 지원 파일을 활용하며, DP-18의 요약 전용 최소 정책을 함께 설계한다. AI 거버넌스 포털과 기관 실연계는 추가하지 않는다. 일정 마감 조건은 없다.

연결 요구: F-012·014·015·018, T-022·024·027·028. 이 문서의 1차 범위는 DP-07 전체 완료 기준과 구분한다. 번역·자유 재작성·PDF 출력·여러 문서 종합은 후속이다.

## 1차 사용 흐름

1. 현재 조직에서 읽을 수 있고 게시 완료된 문서의 정확한 버전 한 개를 선택한다.
2. 핵심 항목 수를 3개 또는 5개로 선택하고 요약을 실행한다. 자유 입력 지시문은 받지 않는다.
3. 원문에서 선택된 문장을 핵심 항목으로 표시한다. 각 항목의 문서명·버전·행/페이지/문단/셀 출처를 확인한다.
4. 같은 원문 버전을 다시 요약하면 별도 실행 이력을 만든다. 이전 결과는 덮어쓰지 않는다.
5. 결과와 출처를 Markdown 파일로 내려받는다. 내려받기 때도 현재 권한을 확인한다.

화면 명칭은 ‘문서 요약’, 방식 표시는 ‘원문 발췌 요약’이다. 원문 문장 선택 기능이며 문장 재작성이나 번역으로 표시하지 않는다. 후보가 적으면 실제 선택 수만 표시한다. 전체 원문 의미를 이해하거나 핵심 내용을 모두 포함했다고 주장하지 않는다.

## 지원 경계

- TXT·Markdown과 현재 제한적 텍스트 PDF·DOCX·XLSX의 게시된 canonical UTF-8를 사용한다. 재파싱·새 형식 지원을 추가하지 않는다.
- 1회 문서/버전 1개, 입력 메시지 전체 6,000 토큰 이하, 후보 최대 128개, 출력512 토큰 이하. 한도 초과는 명시적으로 거부하고 앞부분만 잘라 요약하지 않는다.
- 후보는 기존 문서 계획의 완전한 근거 단위 중 원문 오프셋을 확인한 항목이다. 조각난 문장·구조 레이블만 있는 항목은 제외한다. 하나의 완전한 단위가 한도를 넘으면 실패를 표시한다.
- 요약 시 새 임베딩 호출을 하지 않는다. 기존 승인된 저비용 모델/요금 snapshot을 사용하고, 개발 검증은 모의 실행으로 진행한다. 실제 요약 1회에 생성 호출 최대 1회; 재생성은 새로운 유료 실행일 수 있음을 화면에 표시한다.
- 이미 내려받은 파일의 사후 회수는 제공하지 않는다. 서버의 후속 조회·재생성·내려받기는 권한 회수 후 차단한다.
