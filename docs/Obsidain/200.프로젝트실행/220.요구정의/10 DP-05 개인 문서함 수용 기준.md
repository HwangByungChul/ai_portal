# DP-05 개인 문서함 수용 기준

승인 근거: [[11 DP-05 개인 문서함과 질문 첨부 상세 작업 계획]]. 기존 GraphRAG·문서 처리와 질문 자료 선택을 재사용한다.

| ID | 수용 기준 | 검증 |
|---|---|---|
| AC-D05-01 | 로그인한 현재 조직 사용자만 자기 개인 문서를 등록한다. 조직·소유자·공유 대상 입력은 422로 거절한다. | HTTP/DB/원문 파일 |
| AC-D05-02 | UTF-8 TXT/Markdown만 받는다. 128KB·40,000자·제목 200자·전체 요청 144KB 제한을 유지한다. | 형식·용량 경계 |
| AC-D05-03 | 동일 접수 ID·내용은 같은 문서와 작업을 반환한다. 변경 내용은 409이고 추가 색인 호출이 없다. | 중복 접수·원장 |
| AC-D05-04 | 본인이 올린 개인 문서의 제목·상태·게시 여부·삭제 정리 상태를 본다. 다른 사용자와 조직의 문서·작업은 목록 및 직접 ID 조회로 노출되지 않는다. | 사용자/조직/관리자 교차 시험 |
| AC-D05-05 | 미게시 문서는 첨부할 수 없다. 게시된 버전만 규정 질의 자료 선택과 근거에 사용한다. | 질문·원문·근거 |
| AC-D05-06 | 본인 문서를 현재 수정 번호로 삭제한다. 삭제 직후 검색·새 질문·기존 답변·근거·평가 접근이 차단된다. 비용/감사 기록은 보존하고 원문은 작업으로 정리한다. | 삭제 전후 접근·원장 |
| AC-D05-07 | 기존 관리자 등록/버전/공유 권한은 유지한다. 개인 업로드 권한으로 조직 문서·타인 문서·관리자 작업을 실행할 수 없다. | 기존 회귀·직접 함수 호출 |
| AC-D05-08 | 계정·조직·멤버십 중단은 저장된 문서 처리 권한에도 적용한다. 세션 만료 자체는 이미 접수된 백그라운드 작업을 취소하지 않는다. | 저장된 주체·회수 시험 |
| AC-D05-09 | 화면은 본인 업로드·처리 확인·삭제·규정 질문 자료 선택을 제공한다. 조직 전환 시 이전 조직의 제목·선택·늦은 응답을 제거한다. | 실제 브라우저·모바일 |

개인 문서 버전 추가, 재시도, 공유, PDF/Office/OCR은 이번 범위 밖이다. 관리자에게 사용자 개인 문서 원문 읽기 권한을 부여하지 않는다.
