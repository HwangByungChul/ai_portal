# DP-06 XLSX 시트와 셀 수용 기준

작성일: 2026-10-07. 사용자가 진행을 승인한 [[17 DP-06 XLSX 파서 확장 상세 작업 계획]]을 구현 가능한 계약으로 구체화한다. 목적은 최소 비용의 개인 학습·제안 시연이며, 기관 운영/Office 전체 호환성이 완료 기준은 아니다.

## 지원과 거부

Transitional SpreadsheetML의 표시 가능한 시트10개 이하. inlineStr/sharedStrings(서식 있는 문자열은 텍스트 순서 보존), 숫자,0/1 불리언, 명시적 ISO 날짜(t=d)를 지원한다. 숫자의 저장 문자열을 유지하고 불리언만 TRUE/FALSE로 표시한다. 기본 숫자 서식0/1/2/49만 허용한다. 날짜 직렬수·통화·백분율·사용자 정의 숫자 서식은 거부한다. 명시적 ISO 날짜는 검증 후 원래 문자열을 유지한다. 수식·캐시 결과(t=str)·오류 값은 거부한다.

숨김/veryHidden 시트·행·열, 병합, 필터/접힌 행·열, 그림/차트/주석/피벗/첨부/매크로/외부 관계·연결·미지원 부품과 의미 있는 미지원 XML 구조는 파일 전체를 거부한다. 값/시트 이름을 조용히 누락하지 않는다. 메타데이터·글꼴·페이지 설정은 텍스트가 아니며 시각적 서식 재현 범위 밖이다. 시트/셀의 텍스트는 검사를 적용하지만 docProps는 개인정보 검사 범위 밖이다.

## 위치와 canonical

워크북의 실제 시트 순서 및 원래 셀 주소를 보존한다. 시트 이름은1~31자, Excel 금지문자/제어문자 없음, 대소문자를 무시한 중복 없음. 행/셀은 오름차순이고 중복 없음. 주소는A1~XFD1048576이며 행 XML과 셀 주소의 행이 일치해야 한다.

각 시트마다 `시트: 이름` 단위를 먼저 추가한다. 빈 시트의 이름도 텍스트에 포함해 수집 검사를 적용한다. 각 비어 있지 않은 셀은 `셀 A1: 값`으로 추가한다. 단위 사이 두 줄바꿈, 셀 값의 줄바꿈·탭 보존. 전체가 빈 셀만 가진 파일은 XLSX_EMPTY로 거부한다.

위치 맵은 정확한 키 집합을 갖는다: 시트 헤더 `{kind:sheet,sheet_index,sheet_name,start,end}`, 셀 `{kind:cell,sheet_index,sheet_name,cell,start,end}`. Unicode 코드포인트 오프셋이며 첫start0, 이후start=이전end+2, 마지막end=문자 수. 헤더/셀의 실제 시트 이름·번호가 일치하고 셀은 시트 헤더 뒤 오름차순이다. canonical 내 레이블까지 위치 단위에 포함한다. 헤더10개+비어 있지 않은 셀2,000개가 최대2,010개 단위다. 페이지 번호를 추정하지 않는다.

## 자원·보안·기존 계약

원본128KB, canonical40,000자/128KB, 시트10개, 비어 있지 않은 셀2,000개, sharedStrings10,000항목. ZIP200부품/개별1MB/합계4MB/압축비100배, XML 깊이50/합산20,000노드. CPU2초·실행5초·50ms 간격 RSS512MB 초과 종료. RSS는 하드 메모리 상한이 아니다. 격리/감시 장애는 차단한다.

기존 현재 권한·접수 제한·확정 재접수 조회 후 파싱하고 제목+시트 이름+셀 전체를 수집 검사한다. 확정 재접수는 파서/파일/작업 추가0. 원본과 canonical SHA-256 각각 보관. 파싱 중 권한 회수·파일/위치 변조·원본 유실 차단. 조직 간 공유는 지정 버전에만 적용하고 회수 후 답변·근거·원본 접근도 차단한다. 기존 sealed location 네 필드 및 SQL000~024/주 DB 원본 데이터를 유지한다. 다운로드 MIME은 application/vnd.openxmlformats-officedocument.spreadsheetml.sheet, 파일명document.xlsx다. 유료 호출 없이 합성 자료로 검증한다.
