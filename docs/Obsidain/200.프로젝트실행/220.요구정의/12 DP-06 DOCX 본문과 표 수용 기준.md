# DP-06 DOCX 본문과 표 수용 기준

승인된 [[15 DP-06 DOCX 파서 확장 상세 작업 계획]]을 실행한다. 초기 지원은 Transitional OOXML 본문 문단·중첩/병합 없는 표이다. 페이지를 추정하지 않는다.

| ID | 수용 기준 |
|---|---|
| AC-DX-01 | .docx·정확한 DOCX MIME·ZIP 시그니처·OOXML 필수 타입/관계/본문이 일치해야 한다. TXT/PDF MIME 위장은 거절한다. |
| AC-DX-02 | 원본128KB, 추출40,000자/128KB, ZIP 항목200개, 전체 해제4MB, 개별 부품1MB, 압축률100배 이하, XML 깊이50/노드20,000, 비어 있지 않은 추출 단위2,000 이하. CPU2초/실행5초/RSS512MB 초과 감시를 유지한다. |
| AC-DX-03 | 절대/상위/역슬래시/중복 ZIP 경로, 심볼릭 링크, 암호화, 미지원 압축, DTD/엔터티/외부 참조/매크로/OLE/첨부는 차단한다. 디스크로 압축을 풀지 않는다. |
| AC-DX-04 | Word 본문 문단과 표 셀을 문서 순서로 추출한다. 빈 문단/셀은 원래 번호를 차지하지만 검색 텍스트 단위로 저장하지 않는다. 셀 안 문단은 줄바꿈으로 구분한다. |
| AC-DX-05 | 머리말/꼬리말/주석/각주/변경 추적/텍스트 상자/필드/콘텐츠 컨트롤/이미지/중첩·병합 표/자동 번호 목록은 미지원으로 거부한다. 일반 글꼴/서식은 지원하며 본문 문자만 추출한다. |
| AC-DX-06 | 기존 권한·접수 제한·재접수 계약을 파싱 전에 확인한다. 제목+추출 전체에 최소 수집 검사를 적용하고 색인/검색 재검사를 유지한다. |
| AC-DX-07 | canonical 텍스트와 원본 DOCX를 별도로0600 저장하고 각각 SHA-256을 보존한다. 문단/표 셀 맵은 불변 origin에 기록한다. |
| AC-DX-08 | 봉인된 근거 위치 네 필드는 유지한다. 조회에서만 문단/표 셀 표시를 파생한다. 원본 다운로드는 권한·두 지문 재확인 후 등록한 DOCX 바이트를 반환한다. |
| AC-DX-09 | 개인/관리자 업로드→게시→규정 질문→문단/표 셀 근거→원본 다운로드·삭제 정리를 확인한다. 타 주체/조직과 회수 후 접근은 차단한다. |
| AC-DX-10 | 기존 TXT/Markdown/PDF·멀티테넌트·GraphRAG·대화/평가/요금 및 전체 화면 영향 회귀를 실행한다. 기존000~024 SQL과 주 DB 기존 열/행을 보존한다. 유료 호출0회. |

수집 정책은 기존 document-ingest-v1이며 DOCX 원본의 문서 속성/서식 메타데이터까지 개인정보 검사를 확장하는 기능은 이번 범위가 아니다. 미지원 구조를 조용히 누락하지 않는다. 허용 OOXML 부품과 관계 타입은 상세 설계의 명시적 목록만 사용한다. XLSX/PPTX/OCR 및 전체 정책 관리 완료와 구분한다.
