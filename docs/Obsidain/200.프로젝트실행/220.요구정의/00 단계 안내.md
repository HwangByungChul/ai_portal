# 220.요구정의

목표: 액터·유스케이스·RFP/MVP 요구 및 시험 추적을 정의한다.

현재 상태: **상세 작업 계획 작성 완료, 요구 초안 작성 전**. 210 종합 확정 상태를 입력으로 확인한다. 계획 작성은 단계 완료를 의미하지 않는다.

## 관리 항목

- 선행 입력 및 관련 요구사항
- 계획 산출물과 문서 ID
- 작성·검토·확정 상태
- 실제 구현·시험 증거 위치
- 미결정 사항 및 다음 단계 전달사항

관련: [[00 프로젝트 안내]].

상세 계획: [[200.프로젝트실행/220.요구정의/01 요구정의 상세 작업 계획]]. 예상 문서 작업량은 4.5시간이며 기존 1주차 시간 배분 안에 포함한다.
