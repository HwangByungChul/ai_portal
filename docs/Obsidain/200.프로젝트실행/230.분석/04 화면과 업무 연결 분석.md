# 화면과 업무 연결 분석

## 결론과 작업 상태

A230-03 문서 작업을 완료했다. 기존 BNK 시연의 조직 선택 헤더, Agent 카드, 채팅·이력·근거 패널, 문서/사용자/운영 목록은 **화면 구성 참고 자산으로 활용**한다. GraphRAG 프론트의 표·폼·탭·메뉴 틀도 일부 재사용할 수 있으나 대부분 정적 또는 모의 동작이다. 실제 사용자 포털, 테넌트 전환, 현재 권한, 근거 조회, 지속 이력, 취소, 공유 버전 회수, 중지·한도는 서버 계약과 함께 연결해야 한다.

특히 API 호출 코드가 있는 ChatbotWidget와 KnowledgeBase는 현재 App의 화면 경로에 연결되지 않았다. 시연 PNG, 코드 파일 존재, API 호출 구문, 실제 동작 검증을 서로 구분한다. 새로운 프로젝트의 src는 이번에 수정하지 않았다. 브라우저/백엔드/DB 실행, 원본 테스트, 유료 API 호출은 모두 미수행이다.

## 확인 범위와 근거 수준

- BNK 원본의 시연 PNG 42개를 목록 분류하고, 사용자 기본/2차·관리 핵심·Home 비교 등 21개를 직접 시각 확인했다. 나머지 21개는 이름/위치 분류만 했으며 세부 내용이나 동작을 추정하지 않는다.
- SHA 기준 서로 다른 PNG는 41개다. 붉은 Home 이미지의 기본/2차 경로 2개는 바이트가 같으며, 푸른 Home은 별도 이미지다. 42개 파일을 42개의 독립 기능으로 계산하지 않는다.
- 4.2 사용자 5종은 기본/2차 각각 있고, 4.3 Marketplace 6종, 4.4 Builder 7종, 5 거버넌스 8종, 6 운영 8종, Home 3파일로 분류했다. 숫자 군 합계는 10+6+7+8+8+3=42다.
- 2차라는 파일명은 수정안의 단서다. 기본안보다 확정/최신이라는 승인 근거는 없으며, Home도 파일명 v1만으로 공통 디자인 확정을 하지 않는다.
- GraphRAG 원본 HEAD와 작업 파일은 선행 기준 그대로다. frontend는 원본 Git 미추적 디렉터리이므로 HEAD만으로 해당 화면 버전을 재현할 수 없고 선행 파일 SHA를 기준으로 삼는다.

시각 재사용은 배치/정보 구조를 참고한다는 의견이다. PNG를 React 소스나 실제 구현으로 간주하지 않고, 기업명·사용자명·기관 규정 예문은 MVP 합성 명칭으로 교체한다. 시연의 품질 점수·사용량·가용성·성능·보안 통과 문구는 검증 자료가 없어 실측/보장 표시로 옮기지 않는다.
