# 전체 화면과 기술요건 구현 대조표

본표는 [[200.프로젝트실행/230.분석/09 전체 기능명세서 기준 개발 완료 여부 검토 보고서]]의 별첨이다. 원본 IA150/T62를 누락 없이 보존하고 현재 업무 흐름으로 대조했다. 경로 변경/여러 화면의 병합은 허용하지만 원본 하위동작이 사라진 것을 완료로 인정하지 않는다. 같은 고정설정 화면을 여러 원본ID의 제한 기반으로 연결한 것이 여러 제품 화면을 완성했다는 뜻은 아니다. 부분41은 ‘원본 화면41개 완성’이나 화면 진척률이 아니다.
