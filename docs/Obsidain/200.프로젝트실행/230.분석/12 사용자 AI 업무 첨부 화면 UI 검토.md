# 사용자 AI 업무 첨부 화면 UI 검토

관련: [[23 포털 UI UX 확정과 사이트 분리 검토]], [[02 포털 UI UX 작업 기록]], [[35 DP12-03 사용자 전역 Agent 실행 이력과 철회 기록 구현 결과]].

## 사용자 요청과 근거

2026-10-12 사용자가 로그인 후 첨부한 화면에 대해 검토를 요청했다. 첨부는 사용자 사이트의 AI 업무 메뉴이며 A-ADM 계정·가상 조직 A·조직 관리자 표시를 확인했다. 첨부 원본은 5074×2334이고 대화 표시에서는 2048×942로 축소되어 있으므로 작은 글씨의 인상만으로 실제 CSS 글자 크기 결함을 단정하지 않는다. 사용자 A안 홈·관리 A안 홈·관리 B안 승인 화면 결정은 유지한다.

## 확인 결과

- 첨부는 확정된 홈 화면이 아니라 사용자 AI 업무 대화 화면이다. 홈은 왼쪽 홈 메뉴 또는 http://127.0.0.1:5173/user/home 이다.
- 관리자 계정으로 사용자 사이트를 보는 구성이 코드에 존재한다. UserApp은 선택 조직 can_manage 또는 플랫폼 capability에 따라 관리자 사이트 이동 링크를 제공하며 관리자 계정 로그인만으로 관리자 홈으로 자동 이동하지 않는다. 관리자 홈은 http://127.0.0.1:5174/manage/admin 이다. 관리자 사이트 서버 권한 판정 자체는 이번 검토에서 재시험하지 않았다.
- 공통 styles.css의 .content는 width:100%, max-width:1500px, margin:0 auto, padding:38px이다. 초광폭 화면에서 본문이 중앙 좁은 영역에 머무는 원인을 확인했다. 실제 브라우저 viewport·배율 측정은 수행하지 않았다.
- .chat-layout은 대화 목록 210px와 나머지 본문을 배치한다. .message-list는 min-height:240px, margin:24px 0으로 화면 높이에 따라 늘어나는 대화 작업영역을 구성하지 않는다. 입력창도 일반 문서 흐름에 있다.
- 첨부에서 Agent 선택 카드가 선택 필드와 두 안내 문구 대비 크고 대화 목록·빈 대화 영역의 구획이 약하다. 실행 이력 버튼은 별도 줄에 있고 내비게이션에도 같은 목적지가 있다.
- 질문 보내기 비활성은 입력이 비어 있을 때 코드가 의도적으로 적용하는 상태다. 이미지에 오류 알림은 보이지 않는다. 이것만으로 API·실제 모델·문서 검색의 정상 실행을 검증한 것은 아니다.

## 수정 제안과 순서

1. AI 업무 화면에 별도 레이아웃 범위를 두어 공통 홈·관리 화면에 영향을 주지 않고 넓은 화면을 활용한다. 예시로 대화 목록 260~300px, 대화 작업영역 가변 폭, 실제 메시지는 읽기 편한 제한 폭으로 구성한다. 수치는 구현 전 제안이다.
2. 대화 영역은 사용 가능한 화면 높이에 맞추고 메시지 영역에 스크롤을 제공한다. 입력창은 작업영역 하단에 배치하며 좁은 화면·모바일 키보드·긴 답변에서 가림을 검증한다.
3. Agent 선택을 상단 간결한 도구 영역으로 정리하고 빈 대화 시작 안내와 새 대화 버튼을 명확하게 배치한다. 예시 질문을 추가하더라도 클릭만으로 유료 실행하지 않고 입력 후 사용자가 전송한다.
4. 사용자 사이트·관리자 사이트 명칭과 이동 링크를 명확히 표시한다. 조직 관리자 역할 배지는 현재 사이트 표시와 구분한다. 사용자 홈과 관리자 홈의 확정된 방향은 변경하지 않는다.
5. 실행 이력 링크의 문구·배치를 정리한다. 기존 일반 대화와 독립 Agent 실행의 저장·권한 계약은 유지한다.

## 실제 파일과 검증 범위

읽기 검토 파일: src/frontend/apps/user-web/src/App.tsx, src/frontend/src/ChatPage.tsx, src/frontend/packages/ui/src/styles.css, src/frontend/packages/ui/src/portal.css, src/frontend/packages/ui/src/PortalShell.tsx 및 설계23·최신 작업 기록.

변경한 실제 파일은 이 분석 노트와 작업 기록뿐이다. 앱 코드·DB·인증·계정 변경은 없다. 근거는 사용자 첨부 이미지와 현재 코드의 레이아웃/경로 대조다. 브라우저 재현·뷰포트 계측·기능 호출·자동시험·Obsidian 읽기 화면 검증은 수행하지 않았다. CSS 수정이 적용되었다거나 전체 기능이 완료되었다고 표현하지 않는다.

다음 작업은 위 개선안의 실제 React/CSS 적용과 1440/1920/2560px 및 모바일에서의 화면 검증이다. 별도 동적 즐겨찾기/My Agent 기능 개발 잔여는 유지한다.
