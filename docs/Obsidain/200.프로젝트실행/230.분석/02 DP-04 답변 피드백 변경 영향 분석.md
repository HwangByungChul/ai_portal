# DP-04 답변 피드백 변경 영향 분석

대화·실행·메시지는 소유자와 조직에 묶여 있고 DP-03은 삭제 후 조회를 차단한다. 이를 재사용하여 feedback_target이 현재 완료 답변을 검사한다. 일반 답변과 RAG 모두 현재 접근 가능한 assistant 메시지가 있어야 한다. RAG 자료 권한이 회수되면 피드백도 조회·변경하지 못한다.

기존 실행·사용량·근거 테이블은 변경하지 않는다. 신규 평가 테이블과 다섯 개의 좁은 정책 함수만 추가한다. 관리자 집계는 개인 답변 읽기 권한을 부여하지 않고 집계 전용 함수에서만 수행한다. 명시적인 feedback.summary_read 권한 판정은 현재 can_manage와 매핑하며 DP-16에서 세분화할 수 있도록 별도 함수에 둔다.

평가 화면은 ResponseFeedback으로 분리하고 저장된 assistant 메시지와 최종 답변에 붙인다. 피드백 목록 화면은 별도 FeedbackSummaryPage로 분리한다. 기존 scoped 요청과 조직 전환 시 취소·늦은 응답 폐기 처리를 사용한다.

022 변경 적용 시 기존 000~021 체크섬과 31개 기존 테이블의 컬럼·행을 비교한다. 시연 서버는 전체 회귀 시험 전에 정리하고 검증 후 모의 모델로 복구한다. 실제 외부 모델은 호출하지 않는다.
