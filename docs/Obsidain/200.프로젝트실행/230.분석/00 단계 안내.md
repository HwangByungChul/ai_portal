# 230.분석

목표: 기존 코드·화면·업무·데이터·외부 연계를 분석한다.

현재 상태: **A230-01~04 원본·코어/백엔드·화면 분석 및 합성 원문/평가셋 작성 완료**. 다음은 A230-05 분석 종합과 240 설계 전달이다. 실제 구현/시험은 미수행이며 230 단계 종합 검토는 남아 있다.

## 관리 항목

- 선행 입력 및 관련 요구사항
- 계획 산출물과 문서 ID
- 작성·검토·확정 상태
- 실제 구현·시험 증거 위치
- 미결정 사항 및 다음 단계 전달사항

관련: [[00 프로젝트 안내]].

상세 계획: [[200.프로젝트실행/230.분석/01 분석 상세 작업 계획]]. 예비작업량3.5시간은기존1주차배분에포함하며실제소요에따라조정한다.

기준문서: [[200.프로젝트실행/230.분석/02 분석 대상과 기준 버전]]. 원본103개작업파일/선별BNK93개자료목록을기록했다.

재사용분석: [[200.프로젝트실행/230.분석/03 GraphRAG와 백엔드 재사용 분석]]. 요구41개를현재파일근거·보완/설계입력에연결했다.

화면 분석: [[200.프로젝트실행/230.분석/04 화면과 업무 연결 분석]]. 시연 목록 42개/시각 확인 21개와 코드 근거 17개를 구분하고 UP12/AP13을 연결했다.

평가 기준: [[200.프로젝트실행/230.분석/05 합성 데이터와 평가 기준]]. 논리 문서6/버전7·정답 근거18/관계16·질문20(6/6/4/4)을 작성했으며 정적 점검만 완료했다.
