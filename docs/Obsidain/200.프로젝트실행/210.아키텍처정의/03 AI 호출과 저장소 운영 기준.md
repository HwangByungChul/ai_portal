# AI 호출과 저장소 운영 기준

## 선행 결정

[[100.프로젝트계획/03 프로젝트계획서]]와 210의 테넌트 격리·모듈 경계는 사용자 승인되었다. OpenAI API 사용 예정·10월 최대 30,000원·고정 Agent 2개·공통 호출·조직별 권한과 지속 저장이 기준이다.

## 이번 검토 순서

1. 실제 OpenAI API 계정의 사용 준비 상태를 확인한다. 사용자가 2026-10-04 “1”로 API 계정·사용 설정·키 발급 준비 완료를 답했다. 이는 사용자 확인이며 실제 호출·모델 접근 시험은 아직 수행하지 않았다.
2. 공식 제공 모델/가격 자료를 확인해 답변 모델 1개와 임베딩 모델의 후보·선정 기준을 제시한다. 사용자의 최소 비용 지시에 따라 아래 기본 모델을 선정했다. 모델 선택을 위한 추가 질문·유료 비교 시험은 진행하지 않는다.
3. 호출 제한·예산 대조·재시도·실행/작업 상태와 저장소 운영 기준을 검토한다.
4. 운영 기준 승인 후 210 전체 결과를 정리하고 220 요구정의에 전달한다.

## 독립적으로 정리할 운영 기준안

- 일반/RAG Agent는 같은 기본 답변 모델을 사용해 초기 비교와 운영을 단순화한다. 생성과 임베딩은 용도가 다르므로 별도 계약·버전·usage를 기록한다.
- 관계 추출은 규정 데모의 기존 규칙 기반 추출을 먼저 평가하고, 필요하면 LLM 추출의 추가 예산/품질을 검토한다. 그래프 관계와 근거 정확성은 어느 방식에서도 시험한다.
- 모의/실제 모델 실행을 구분해 기록한다. 반복 권한/오류 시험은 모의 모델로 수행하며 실제 호출은 대표 시나리오 검증에 집중한다.
- 3만원은 두 조직과 모든 생성/임베딩/LLM 추출(사용 시)/재시험을 합친 프로젝트 API 상한이다. 조직별 한도만 검사하지 않는다.
- 실행 허가와 예상 사용량 예약, 실제 usage/실패/불명 정산을 하나의 원장 책임으로 둔다. 동시 요청에서도 예상 비용을 중복 사용하지 않도록 설계한다.
- 단가·사용량·통화·환산 기준과 시점을 남기며 실제 공급자 사용량을 대조한다. 원화 예산을 달러 단가와 숫자만 직접 비교하지 않는다.
- 키는 서버에서 설정하고 사용자 화면·계획 문서·Git에 저장하지 않는다. 현재 대화에서도 키 값을 요청하지 않는다.
- 호출 Timeout·취소·재시도에는 횟수·상태·사용량 확인 기준을 둔다. 공급자 중복 호출 가능성이 있는 재시도는 식별/정산을 고려한다.
- 원문/색인 버전과 처리 모델을 기록하고 변경 없는 문서의 반복 임베딩을 방지한다. 모델이나 문서 버전이 바뀌면 새 처리와 비용을 구분한다.
- DB 마이그레이션 계정과 앱 런타임 계정을 분리한다. 앱과 색인 Job은 RLS/권한 경계를 지키며 Job은 자체 DB 세션을 사용한다.
- 실행/대화/Job 상태는 지속 저장한다. 재시작 시 완료되지 않은 Job을 임의 완료로 표시하지 않고 재실행/실패 판정을 설계한다.
- 문서 삭제/공유 회수는 검색·근거·다운로드 권한에 반영한다. Graph 공유 개체의 삭제는 남아야 할 허용 관계/근거를 함께 검토한다.

이 항목은 검토안이다. 실제 모델·단가·입출력 한도·종결 상태 전이·테이블/트랜잭션·권한 SQL은 승인된 운영 기준을 입력으로 240에서 상세화한다.

## 최소 비용 기본 모델 결정

2026-10-04 사용자 지시: “모델 설정, 비용 산정이 mvp 구현 하는데 중요한가요? 최소 비용으로 선정해서 진행 바랍니다.” 모델 선택과 상세 비용 계산에 추가 검토 시간을 쓰지 않고, 기존 프로젝트와 연결하기 쉬운 저비용 조합으로 진행한다. 전체 제공 모델 중 절대 최저가나 실제 품질 검증 완료를 뜻하지 않는다.

| 용도 | 선정 모델 | 적용 |
|---|---|---|
| 일반/RAG 답변 | gpt-4o-mini | 공통 기본 모델 하나로 고정 |
| 문서/질의 임베딩 | text-embedding-3-small | 기본 1536차원, 변경 없는 문서의 재처리 방지 |

2026-10-04 확인한 공식 일반 단가는 USD/100만 토큰 기준 답변 입력 $0.15·출력 $0.60, 임베딩 입력 $0.02다. 캐시/Batch 할인은 기본 예산 계산에 기대지 않는다. 가격 근거: [gpt-4o-mini](https://developers.openai.com/api/docs/models/gpt-4o-mini), [text-embedding-3-small](https://developers.openai.com/api/docs/models/text-embedding-3-small). 차원 근거: [공식 임베딩 가이드](https://developers.openai.com/api/docs/guides/embeddings).

다중 모델 선택 화면·자동 모델 전환·유료 모델 비교·동적 가격 동기화·정교한 비용 분석 화면은 후속 범위다. 모델명은 서버 설정으로 변경 가능하게 두되 MVP 화면에는 모델 설정 기능을 만들지 않는다. 기존 gpt-4.1-mini 비교 제안은 이번 수행 범위에서 제외한다. 품질은 대표 평가 질문으로 확인하며 문제가 있으면 우선 검색·근거·프롬프트를 점검한다.

## MVP에서 필요한 최소 호출·비용 통제

- 10월 API 예산 상한 30,000원은 유지한다. 기본 사용량 기록과 한도 차단은 멀티테넌트 검증에 필요한 범위로 유지하며 정교한 과금 기능으로 확대하지 않는다.
- 공통 호출 경로에서 조직·실행·모델·입출력 토큰·성공/실패/사용량 불명을 기록한다. Usage/Quota가 원장을 소유한다.
- 입력/출력 길이·동시 호출·조직별 한도·프로젝트 합산 한도를 제한한다. 예상 사용량 예약과 호출 완료 기록은 최소 구현으로 둬 동시 요청이 남은 한도를 중복 사용하지 않게 한다.
- 상세 비용 예측과 25,000원/5,000원 분할안의 별도 승인 절차는 생략한다. 고정 단가와 운영자가 설정한 보수적 환산값으로 단순 추정하며, 실제 사용 내역을 대조해 상한 전에 호출을 중지한다. 정확한 호출 한도와 여유값은 240에서 구현값으로 정한다.
- 반복 개발/권한/오류 시험은 모의 모델을 사용하고 실제 호출은 대표 시나리오에 제한한다. 문서 변경이 없으면 재임베딩하지 않는다.
- 관계 추출은 기존 규칙 기반 방식을 먼저 사용한다. 자동 고가 모델 전환·무제한 재시도·자동 추가 결제는 사용하지 않는다.
- 실제 모델 접근과 응답은 후속 구현/검증 단계에서 확인한다. 앱 추정액을 실제 청구 상한 보장으로 표시하지 않는다.

## 현재 결정과 남은 검토

API 준비는 사용자 확인 완료, 최소 비용 모델 선정과 검토 간소화 방향은 사용자 지시로 확정했다. 저장소·Job·삭제/공유 회수 등 앞의 운영 기준은 210 종합 검토에 포함한다. 이번 답변을 모든 운영 기준 또는 앱 구현 착수의 승인으로 확대하지 않는다.

## 작성 상태와 근거

환경 준비 답변 기록·공식 모델/가격 확인·후보 비교·운영 기준 초안을 작성했다. 저비용 기본 모델은 사용자 지시에 따라 선정했다. 상세 비용 산정의 별도 의사결정은 생략하고 최소 사용량/한도 기능을 유지한다. 저장소 등 운영 기준의 종합 검토는 남아 있다. API 호출·모델 설치·키 설정은 수행하지 않았다. OpenAI Docs 스킬로 공식 문서만 확인했다.
