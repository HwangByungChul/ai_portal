# AI 호출과 저장소 운영 기준

## 선행 결정

[[100.프로젝트계획/03 프로젝트계획서]]와 210의 테넌트 격리·모듈 경계는 사용자 승인되었다. OpenAI API 사용 예정·10월 최대 30,000원·고정 Agent 2개·공통 호출·조직별 권한과 지속 저장이 기준이다.

## 이번 검토 순서

1. 실제 OpenAI API 계정의 사용 준비 상태를 확인한다. 사용자가 2026-10-04 “1”로 API 계정·사용 설정·키 발급 준비 완료를 답했다. 이는 사용자 확인이며 실제 호출·모델 접근 시험은 아직 수행하지 않았다.
2. 공식 제공 모델/가격 자료를 확인해 답변 모델 1개와 임베딩 모델의 후보·선정 기준을 제시한다. 현재 후보·공식 단가는 아래에 정리했으며 채택은 사용자 검토중이다.
3. 호출 제한·예산 대조·재시도·실행/작업 상태와 저장소 운영 기준을 검토한다.
4. 운영 기준 승인 후 210 전체 결과를 정리하고 220 요구정의에 전달한다.

## 독립적으로 정리할 운영 기준안

- 일반/RAG Agent는 같은 기본 답변 모델을 사용해 초기 비교와 운영을 단순화한다. 생성과 임베딩은 용도가 다르므로 별도 계약·버전·usage를 기록한다.
- 관계 추출은 규정 데모의 기존 규칙 기반 추출을 먼저 평가하고, 필요하면 LLM 추출의 추가 예산/품질을 검토한다. 그래프 관계와 근거 정확성은 어느 방식에서도 시험한다.
- 모의/실제 모델 실행을 구분해 기록한다. 반복 권한/오류 시험은 모의 모델로 수행하며 실제 호출은 대표 시나리오 검증에 집중한다.
- 3만원은 두 조직과 모든 생성/임베딩/LLM 추출(사용 시)/재시험을 합친 프로젝트 API 상한이다. 조직별 한도만 검사하지 않는다.
- 실행 허가와 예상 사용량 예약, 실제 usage/실패/불명 정산을 하나의 원장 책임으로 둔다. 동시 요청에서도 예상 비용을 중복 사용하지 않도록 설계한다.
- 단가·사용량·통화·환산 기준과 시점을 남기며 실제 공급자 사용량을 대조한다. 원화 예산을 달러 단가와 숫자만 직접 비교하지 않는다.
- 키는 서버에서 설정하고 사용자 화면·계획 문서·Git에 저장하지 않는다. 현재 대화에서도 키 값을 요청하지 않는다.
- 호출 Timeout·취소·재시도에는 횟수·상태·사용량 확인 기준을 둔다. 공급자 중복 호출 가능성이 있는 재시도는 식별/정산을 고려한다.
- 원문/색인 버전과 처리 모델을 기록하고 변경 없는 문서의 반복 임베딩을 방지한다. 모델이나 문서 버전이 바뀌면 새 처리와 비용을 구분한다.
- DB 마이그레이션 계정과 앱 런타임 계정을 분리한다. 앱과 색인 Job은 RLS/권한 경계를 지키며 Job은 자체 DB 세션을 사용한다.
- 실행/대화/Job 상태는 지속 저장한다. 재시작 시 완료되지 않은 Job을 임의 완료로 표시하지 않고 재실행/실패 판정을 설계한다.
- 문서 삭제/공유 회수는 검색·근거·다운로드 권한에 반영한다. Graph 공유 개체의 삭제는 남아야 할 허용 관계/근거를 함께 검토한다.

이 항목은 검토안이다. 실제 모델·단가·입출력 한도·종결 상태 전이·테이블/트랜잭션·권한 SQL은 승인된 운영 기준을 입력으로 240에서 상세화한다.

## 모델 후보와 추천

2026-10-04 공식 문서에서 일반 텍스트 호출 단가를 확인했다. 아래는 USD/100만 토큰이며 캐시/Batch 할인은 예산 기본 계산에 적용하지 않는다.

| 용도 | 후보 | 입력 | 출력 | 판단 |
|---|---|---:|---:|---|
| 기본 답변 | gpt-4o-mini | $0.15 | $0.60 | 비용 우선 초기안. 일반/RAG Agent에 같은 모델 적용 |
| 비교 답변 | gpt-4.1-mini | $0.40 | $1.60 | 기본 모델이 평가에서 부족할 때 제한 비교. 자동 폴백 아님 |
| 임베딩 | text-embedding-3-small | $0.02 | 해당 없음 | 문서/질의 임베딩 공통 모델, 기본 1536차원 |

추천은 **gpt-4o-mini + text-embedding-3-small**이다. 가격만으로 한국어 규정/책무 품질을 보장하지 않는다. 예상 질문의 허용 근거와 거부 결과를 평가하고 부족하면 검색/근거 구성을 먼저 점검한 후 gpt-4.1-mini 비교를 검토한다. 비교 모델 호출도 3만원 예산에 포함하며 자동으로 전환하지 않는다.

가격 근거: [gpt-4o-mini](https://developers.openai.com/api/docs/models/gpt-4o-mini), [gpt-4.1-mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [text-embedding-3-small](https://developers.openai.com/api/docs/models/text-embedding-3-small). 임베딩 차원 근거: [공식 임베딩 가이드](https://developers.openai.com/api/docs/guides/embeddings).

기본 임베딩 차원은 신규 실제 저장소 설계에 반영한다. 변경 시 기존 벡터와 섞지 않고 모델/차원/색인 버전 및 재색인 비용을 구분한다. 답변 alias와 실제 사용 model/snapshot을 기록하고 계정의 해당 모델 접근을 호출 전 확인한다. 실제 접근·한국어 품질·성능은 아직 시험하지 않았다.

## 비용 예시와 원화 통제 제안

**계산 예시(사용 예측 아님):** 실제 질의 200회가 각각 입력 3,000·출력 800토큰을 사용하고 문서/질의 임베딩이 총 100,000토큰일 경우, gpt-4o-mini 생성은 $0.09+$0.096=$0.186, 임베딩은 $0.002로 합계 **$0.188**이다. 실제 Prompt·대화 이력·검색 근거·실패/재시도·추출 호출과 실제 출력량이 바뀌면 비용이 달라진다. 환율/세금/수수료는 이 USD 예시에 포함하지 않았다.

원화 비용 통제는 다음 기준을 제안한다.

- 사용자 상한은 30,000원으로 유지한다.
- **앱 관리 기준에서는 사용 확정/불명 예약/진행중 예약을 합산한 예상 총액이 25,000원에 도달하거나 다음 호출로 이를 넘으면 신규 유료 호출을 중지**한다.
- 나머지 5,000원은 실제 공급자 사용량 대조·환산/수수료·늦은 사용량 확정·불명 호출 정리를 위한 여유다. 이를 새 기능 호출 예산으로 자동 개방하지 않는다.
- 모델별 단가·환산 기준·기준 시각을 기록하고 공급자의 실제 사용과 대조한다. 앱 내부 추정의 중지값이 공급자 청구액을 보장하는 장치는 아니다.
- 사용량 불명 호출은 예약을 즉시 해제하거나 0원으로 정산하지 않는다. 확인 전 추가 호출 허가에 보수적으로 반영한다.
- 제공자 오류·예산 중지로 더 비싼 모델이나 다른 조직/제공자로 자동 폴백하지 않는다.

## 현재 확인 항목

API 사용 준비는 확인 완료다. 이제 기본 답변/임베딩 모델과 25,000원 예상 사용 중지·5,000원 대조 여유, 위 운영 기준의 채택을 검토한다. 키·계정 식별자·결제정보 원문은 수집하지 않는다.

## 작성 상태와 근거

환경 준비 답변 기록·공식 모델/가격 확인·후보 비교·운영 기준 초안을 작성했다. 추천 모델/비용 통제·운영 기준은 사용자 검토중이다. API 호출·모델 설치·키 설정은 수행하지 않았다. OpenAI Docs 스킬로 공식 문서만 확인했다.
