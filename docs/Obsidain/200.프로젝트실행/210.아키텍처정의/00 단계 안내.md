# 210.아키텍처정의

목표: 플랫폼·Gateway·GraphRAG·저장소 경계와 개발 기준을 정한다.

현재 상태: **종합 문서 작성·자체 검토 완료, 사용자 최종 검토 대기**. 실제 구현/시험은 미착수다.

- 격리 방식: 공통 테이블 + 서버 권한 + RLS, 사용자 채택 완료.
- 시스템·모듈 경계: 사용자 승인 완료.
- 저비용 기본 모델: 사용자 지시 반영 완료.
- 실행/저장소 운영과 단계 전달: 아래 종합 문서로 최종 검토.
