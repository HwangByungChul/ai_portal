# 현재 위치와 남은 작업

현재 상태는 **핵심 기능의 구현·Mock 흐름 확인 완료, 통합 검증과 최종 보완·인계 전**이다. 기능 구현 완료와 실제 모델 품질·보안 전체 판정·설치 재현 완료는 구분한다. 현재 직접 볼 수 있는 시연은 합성 자료의 Mock 환경이다.

## 이미 확보한 범위

사용자/관리자 포털, 로그인·조직 문맥, 일반 질의·저장 이력, 문서 접수·색인·GraphRAG 근거, Agent 설정·중지·사용량/한도, 색인/정리 Job의 로그아웃 독립성과 현재 주체 권한 검사를 구현했다. 정리 단위 최종 관련 서버371건/화면64건 통과, 이전 색인 단위 전체 서버856건 통과 기록은 각각 증거에 보존한다. 시험 건수를 합산하거나 전체 요구 통과율로 환산하지 않는다.

## 남은 개발과 남은 검증의 구분

남은 개발은 시험에서 발견되는 결함 수정, 실제 모델 실행을 위한 설정/저장 분리와 필요한 보완, 합의된 UI/UX 개선이다. 새 기능 전체를 처음부터 구현하는 단계는 아니지만 개발 종료를 선언할 단계도 아니다. 이미 구현한 기능의 모든 보안·실패 조합과 실제 모델 품질을 확인하는 일이 남아 있다.

추가 기능 요청은 현재 필수 잔여 작업과 분리해 접수한다. 화면 이름→행동→문제/요구→기대 동작을 기록하고, 보안 결함은 우선 조치한다. 편의 기능이나 범위 확대는 설계·일정·비용 영향을 검토해 이번 MVP 반영 또는 후속으로 결정한다. 요청 접수만으로 구현 범위가 확정된 것은 아니다.

## 전체 완료 판단과 일정

필수 요구의 정확한 증거 판정, 실제 모델 검증 결과, 핵심 보안/데이터/정산 결함의 조치, 사용자 피드백 처리 상태, 설치/복원 재현, 최종 산출물이 갖춰져야 완료 판단이 가능하다. 실행하지 못한 항목은 미완료와 사유로 남기고 자동 시험 성공으로 대체하지 않는다.

10/31 목표, 주20시간 이상, 예비80시간(여유10시간 포함)을 유지한다. 개인 실측 공수와 잔여 작업 실측이 없으므로 남은 일수나 완료일을 확정하지 않는다. 실제 확인 결과에 따라 범위·배정을 재검토한다.
