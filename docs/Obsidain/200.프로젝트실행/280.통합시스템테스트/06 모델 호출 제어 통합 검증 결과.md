# T280 모델 호출 제어 보완 결과

**네 가지 모델 작업의 중앙 호출 제어 보완을 완료했다. 전체 280단계와 05 계획의 잔여 검증은 진행 중이다.**

최종 관련 서버 시험 **162건 통과 / 221.54초**, 빌드 및 전체 화면 시험 **64건 통과 / 203.15초**, 핵심 경계 7건의 세 차례 반복 시험 **21회 통과**다. 신규 서버 시험 56건은 관련 162건에 포함된다. 전체 서버 시험을 다시 실행한 수나 합산 고유 시험 수로 표시하지 않는다. 유료 호출과 추가 비용은 모두 0이다.

## 발견한 문제와 보완

| 문제 | 보완 전 관측 | 보완 후 결과 |
|---|---|---|
| 예약 후 공통·조직·Agent 중지 | 문서 호출은 0이지만 미발사 예약과 슬롯이 남음. 세 경우 모두 실패 | 저장된 Job·조직·세대·claim에 묶인 미발사 호출만 한 번 해제 |
| 발사 후 공통·조직 중지 또는 구성 변경 | 확정 비용은 정산되지만 문서가 공개됨. 세 경우 모두 실패 | 현재 정책과 설정 행 잠금 아래 공개 차단. 기발생 비용 보존 |
| 공개 검사 추가 중 정상 색인 회귀 | 행 잠금에는 RLS의 UPDATE 조건도 적용되어 설정 행이 조회에서 제외됨 | 현재 승인된 Job의 설정 잠금만 허용하고 실제 설정 쓰기는 금지. 정상 흐름 재검증 |

기존 000~016 DB 변경 파일은 수정하지 않았다. 새 `017_document_call_control.sql`에서 미발사 해제 함수, 설정 잠금 정책, 최종 공개 검사를 보완했다. DB 변경 파일은 18개, 보호 함수는 77개다. 기존 업무 테이블 31개와 infra 1개, FORCE RLS 17개를 유지한다. 기존 primary DB에 적용했으며, 앞선 17개 변경 기록과 프로젝트·조직 예산 행은 동일하다.

소스 로컬 기록은 `0e7fb9df24748a34563b6d154712eb9fe737811f`이며 정확히 6개 파일이다. 원격 전송과 배포는 하지 않았다.

## 검증한 행동

일반 생성·문서 임베딩·질의 임베딩·RAG 생성에 공통 중지·조직 중지·Agent 중지·구성 변경을 적용했다. 각 경우를 예약 전, 예약 후, 발사 후로 나누어 **48개 입력**을 확인했다.

- 실제 PG 보호 함수를 사용해 허가·발사·정산을 실행했다. 별도 Mock 제공자 호출 수와 원장 행을 대조했다.
- 부모 run/Job의 조직·주체·mode·실제 세대가 call UUID와 일치하고, 예약·정산·해제가 각각 한 번 발생하는지 확인했다.
- 발사 전 차단은 신규 호출 0, 미발사 예약과 슬롯 0이다. 발사 후에는 확인된 사용량을 보존하고 해당 호출을 미발사로 오인해 해제하지 않는다.
- 문서 구성이 예약 전에 바뀌면 최신 구성으로 허가하는 것은 정상이다. run은 접수 당시 구성과 불일치하면 거부한다.
- 정확한 시점의 정책 변경은 소유한 비primary 시험 DB의 SQL로 주입했다. 이 48건은 관리자 API 권한·감사 변경 시험을 대신하지 않는다.
- RAG 준비용 합성 문서 게시의 Mock 호출은 시험 대상 작업의 호출 수와 구분했다.

추가로 위조 claim·다른 조직·이전 세대의 해제 거부, 회수 후 미발사 정리, 발사된 호출의 해제 거부를 확인했다. 실패한 Job의 확정 체크포인트를 재사용한 새 Job은 **추가 제공자 호출 0**으로 게시했고 이전 Job과 원장을 보존했다. 설정 잠금 정책이 실제 설정 쓰기를 허용하지 않는지도 격리 DB의 임시 보호 함수로 검증하고 시험 함수를 제거했다.

가짜 키와 지시문 표식이 공개 오류·Agent 목록·사용량·다른 조직 관리자 응답·캡처 로그에 없는지 확인했다. 현재 화면 빌드와 이번 시험 로그에서 등록된 실제 비밀값 및 합성 보호 표식의 일치는 0이다.

실제 브라우저에서 DUAL-ADM의 A 설정 응답을 지연한 뒤 B로 전환했다. 늦은 A 응답 이후에도 B의 폼과 저장 대상이 유지됐다.

## 남은 검증과 다음 작업

최신 V 하위 판정은 **19 pass / 124 not_run**, 상위는 **2 pass / 39 not_run**이다. 이번 추가 pass는 V-022b·V-025a·V-029a의 정확한 Mock 행동만이다. 전체 V41·ACL16·상세60을 통과한 것은 아니다.

HTTP request-ID부터 run/Job으로 이어지는 첫 연결, 네 작업의 최종 본문 공개 전체 조합, 한도 축소·재개 조합, 진짜 두 연결의 동시 CAS, 모든 개인·다른 조직 문서 제목/본문·Job·예외·로그의 보호 표식, 실제 모델 검증은 남아 있다. 기존 C06/Q20/성능/문서 장애 증거는 수행 당시 기록으로 보존한다.

설계 240.02/04와 AI-07·REQ-08은 문서 Job을 로그아웃과 독립하도록 정했다. 현재 011/013 SQL은 원래 로그인 세션의 회수·만료·유휴 시간을 검사한다. **설계와 SQL의 불일치를 확인했으며, 전용 행동 재현과 보완은 아직 수행하지 않았다.** 기존 계정·소속·문서·Agent 권한 검사를 임의로 완화하지 않았다.

## 보존 및 일정

보호 파일 32개, 역사 파일 108개, 미추적 파일 74개, 원본 GraphRAG의 선택 소스 9개와 HEAD, primary의 기존 31개 테이블과 비밀 설정을 보존했다. A 대표 실배정 500원과 기발생 내부 추정액 0.19원을 유지했고 예약·unknown·슬롯은 0이다. B 실배정은 없다.

기본 Mock, RAG 비활성, primary 자료 0을 유지했다. 종료 후 연결·임시 DB·실행 포트는 0이며 DB는 정지 상태다. 실제 실행 프로필과 필수 입력이 준비되기 전 유료 RAG로 넘어가지 않는다.

270단계의 직접 사용 피드백은 대기 중이고 290·300단계는 미착수다. 10/31 목표, 주 20시간 이상, 기존 80시간과 여유 10시간 계획을 유지한다. 개인 실제 투입 시간은 미측정이다.
