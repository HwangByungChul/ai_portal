# 독립 앱 빌드 경계와 통합 검증 결과

대상: [[200.프로젝트실행/250.구현/22 사용자 관리자 독립 앱과 빌드 분리 구현 결과]]. 이번 단계에서 실제 실행한 시험만 기록한다. 이전 UI11 backend149/browser108은 이전 단계 결과이며 새 결과에 합산하지 않는다.

## 실제 실행

| 실행 | 결과 | 범위 |
|---|---|---|
| 첫 두 빌드 + 경계 검사 | 빌드 성공, 경계 검사 실패 | 제거된 모듈까지 module graph에 포함된 검증 방식 수정 |
| 수정된 두 빌드·typecheck | 성공 | 실제 남은 모듈·최종 JS 경계 검사 |
| `PORTAL_TEST_BUILT=1` 정적 앱 U12_01~06 | 6 passed | 실제 정적 user/admin JS/CSS를 격리 API에 연결 |
| 기존 핵심·새 개발 앱 시험 | 76 passed | 인증/조직·대화·운영·문서/RAG·개인 자료·승인·파일럿·기존 홈 + 새 개발 앱 모바일 이동 |
| 각각 `build:user`와 `build:admin` | 성공 | typecheck·개별 경계·상대 산출물 전체 SHA 불변 |
| 최종 정적 U12_02/05/06/07 | 4 passed | 승인·조직 보존·탭별 조직·로그아웃·모바일/키보드·허용하지 않은 조직 힌트 |

위 시험은 겹치는 시나리오와 static/dev 실행이 있으므로 단일 전수 건수로 합쳐 표시하지 않는다. 초기 정적6 이후 공통 Shell의 조직 전달·링크 스타일을 보완하고 관련4를 재검증했다. backend 소스/DB migration은 변경하지 않아 backend 전수 시험을 반복하지 않았다. source SHA는 UI11의 backend 파일과 대조하여 불변을 확인했다.

최종 사용자 JS299.50kB/gzip90.07kB, 관리자 JS295.22kB/gzip88.66kB, 공통 CSS20.16kB/gzip4.96kB. 실제 남은 프로젝트 모듈은 사용자21/관리자20이다. 각 앱에 index.html·assets·Vite manifest·모듈 목록을 만들었다. 별도 릴리스 산출물이지만 외부 배포 수용 시험은 아니다.

## 결함·수정

- 첫 경계 검사는 Rollup modules의 key 전체를 사용해 renderedLength0인 DocumentSharingPanel을 포함했다. 최종 JS에는 공유 실행 코드가 없었다. 제거되지 않은 코드만 모듈 증거에 포함하고 최종 JS의 관리 실행 경로·UI 토큰 검사도 유지했다. 제외 요구를 약화하거나 화면 시험을 삭제하지 않았다.
- 사이트 이동 링크의 키보드 포커스/표현을 공통 메뉴와 맞췄다. 선택 조직의 전달은 현재 서버 소속 목록 검증 후 적용하고, 선택 완료 전 업무 UI를 차단한다. invalid 조직 힌트가 관리자 권한을 만들지 않는 새 U12_07을 추가했다.
- 독립 명령도 각 앱 경계 검사를 수행하도록 갱신했다. 두 출력 디렉터리를 각자 생성하며 상대 파일 SHA 보존을 확인했다.

## 실제 확인한 동작

사용자 질문 전달 후 자동 POST0·명시적 보내기와 대화 복원, 관리자 타인 승인과 본인 처리 금지·설정 반영, 일반 사용자 직접 관리 주소 거부/관리 API 조회0, 전역 capability와 조직 관리 분리, 사용자 개인 자료 업로드/게시와 관리 API 요청0·개인 사용량, 조직 전환 초안 정리·앱 이동 조직 보존·탭 독립성·같은 출처 로그아웃, 390/1600 넘침·키보드와 실제 화면을 확인했다.

검증용 Vite middleware의 `PORTAL_TEST_BUILT=1`이 독립 dist 산출물을 제공하고 API는 기존 소유 fixture 서버를 사용한다. 테스트 DB는 폐기용 표식·합성 계정·mock이며 주 DB를 초기화하거나 새 모델 키/유료 호출을 사용하지 않았다. 소유 서비스만 정지하고 시험 후 원래 서비스 복구·상태 확인을 수행한다.

## 미검증

상용 IdP/SSO/MFA·별도 도메인/사이트별 BFF 세션·운영 DB·외부 CI 배포·실모델 품질/부하·운영 OS 격리/관측·파일 저장소 재해복구는 후속 단계다. 로컬 독립 빌드와 같은 출처 통합 검증을 상용 서비스 운영 승인으로 표시하지 않는다.
