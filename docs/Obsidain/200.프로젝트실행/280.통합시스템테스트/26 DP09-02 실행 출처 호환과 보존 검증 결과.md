## 발견한 실패와 수정 이력

구현 전 신규 시험1건은 asset_binding 부재로 실패했다. 초기 신규11건에서는10건pass/worker1fail: 새 로그인 origin 대신 이전 fixture 세션을 사용한 시험을 수정했다. 첫 회귀231건의4개 비통과는 migration seed Agent 비활성1건·새 불변 계약에 맞지 않는 기존 빈 snapshot fixture2건·브라우저 harness와 HTTP restart 시험 port8000 중첩1건이었다. 설정을 실제 유효 fixture로 보정하고 시험은 순차 실행했다. 별도 병행 migration 진단에서는 공유 role tuple 갱신 충돌도 발생했으며 순차 재검증에서는 통과했다. 제품의 차단 규칙을 느슨하게 변경하지 않았다. 실패와 보정은 최종 통과 집계와 구분한다.
