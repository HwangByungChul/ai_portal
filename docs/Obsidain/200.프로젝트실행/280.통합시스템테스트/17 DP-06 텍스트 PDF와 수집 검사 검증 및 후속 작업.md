## 범위와 제한

- **이번 묶음 완료:** DP-06 P0 최소 수집 검사·P1 텍스트 PDF·PDF 관련P3 통합. DP-18 중 문서 수집/색인/검색 재검사 최소 규칙.
- **후속:** DOCX→XLSX→PPTX 및 OCR, 일반 질문/출력/Tool 정책·조직별 정책 관리. DP-06·DP-18 전체 완료 상태로 표시하지 않는다.
- 지원 제한: 원본128KB, 추출40,000자/128KB,20페이지, 텍스트 없는 페이지·암호·첨부·폼·링크·자동 실행 거부. PDF 표/다단 배치 추출의 시각적 완전 재현은 보장하지 않는다.
- 후보 규칙의 오탐2개·미탐3개를 명시했다. 검출값·위치를 오류/감사에 남기지 않는다. 일반 개인정보·프롬프트 공격 탐지의 완전성을 주장하지 않는다.
- PDF는 macOS 격리 구현이다. CPU2초/실행5초와50ms 간격 RSS512MB 초과 종료를 적용한다. RSS는 하드 주소 공간 상한이 아니며 감시 사이의 순간 초과가 가능하다. 미지원 OS/격리·감시 장애는 차단한다.
