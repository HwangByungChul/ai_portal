## 실패·제한 이력

초기 복원·일반 승인12pass. 후속 계약32 실행은 HTTP TestClient의 기본 testclient IP 때문에 로그인 실패1·나머지31pass였다. production 인증을 변경하지 않고 테스트 client를127.0.0.1로 맞춰 최종34pass, legacy-backfill1pass를 확인했다.

브라우저 전체28 첫 실행은 기존27pass/복원1fail이었다. 복원 승인 뒤 사용자 화면의 `게시 Agent 실행` region을 부분 일치로 선택하여 `나의 게시 Agent 실행 기록`까지 일치한 테스트 선택자 오류였다. 화면 이름 exact 조건을 추가하고 복원1을 재실행하여 pass를 확인했다. 이미 통과한27은 반복하지 않았으며 브라우저 최신28은 별도 실행 집계다.

추가 legacy-backfill 코드 적용 시 자동 승인 검토가 사용량 한도로 완료되지 않아 해당 파일 쓰기가 실행되지 않았다. 안전성 거부가 아니며 승인 검사를 우회하지 않았다. 사용자 “계속 진행” 뒤 정상 승인 검토로 같은 적용을 재시도하고 독립 검증을 완료했다. 이 일시 중단을 검증 pass로 혼용하지 않는다.
