# DP-05 검증 증거

verification.json은 모의 시험 수·상태·소스 지문·기존 DB 열/행 해시·마이그레이션 보존 결과만 담는다. 계정 비밀번호·모델 키·DSN·원문·질문·의견은 포함하지 않는다. 원본 실행 로그는 각 src/.runtime에 비공개로 보관한다.

초기 영향 회귀 193개 중 186개 통과, 7개는 별도 전용 시험 실행기와 공통 DB 역할 설정 충돌로 시작하지 못했다. 병렬 실행을 종료한 뒤 7개를 순차로 재실행해 모두 통과했다. 최종 DP-05 35개를 모두 재실행했고 기존 회귀와의 중복 30개를 제외한 전체 영향 사례 수는 198개다. 전체 서버 시험군을 모두 재실행한 결과로 표현하지 않는다.

브라우저 전체 77개 중 신규 DP-05 5개를 포함하여 모두 통과했다. 기존 DP-03 3개는 기존 보고기의 익명 시험 식별자로 수록되며 원본 시험 파일과 전체 건수로 추적한다. 모의 결과이며 실제 사용자 인수나 기관 운영 검증을 의미하지 않는다.
