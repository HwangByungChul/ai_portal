# DP-06 공개 검증 증거

verification.json에는 검증 상태/시험 수/소스와 라이브러리 지문/기존 DB 원본 열·행 해시만 보관한다. 계정 비밀번호·모델 키·DSN·검출값·원문·질문은 포함하지 않는다. 원본 실행 로그는 각 src/.runtime에 비공개로 보관한다.

영향 회귀266개와 최종 집중77개는68개가 중복이다. 고유 검증 사례 수는275개이며 별도 collect-only 목록과 일치한다. 초기 회귀 뒤 추가한9개는 PDF 구조/압축 경계8개와 최대 이메일 유사 입력1개다. 최종 집중은 변경된 이메일 검사까지 포함한다. 전체 서버 시험군이 아니라 이번 변경 영향 범위다.

브라우저 전체80개 중 신규D06 3개를 포함해 모두 통과했다. PDF 질문·페이지 근거·원본 바이트·개인 원본의 타 사용자/타 조직 차단·삭제 후 회수, 수집 거부 안내, 관리자 PDF 및 위장 확장자를 검증했다. 기존 모바일·조직 전환·공유·사용량·대화·평가 회귀도 포함한다. 실제 사용자 인수 및 기관 검증은 미실행이다.

실제 운영체제 격리의 프로젝트 읽기/파일 쓰기/통신/하위 프로세스 차단, 비밀 환경변수 미전달, RSS 초과·감시 장애 시 자식 종료를 확인했다. RSS 종료 기준은 하드 주소 공간 한도가 아니며 순간 초과를 허용할 수 있다. 악성 PDF 전체를 탐지했다는 의미가 아니다.
