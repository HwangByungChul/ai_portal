# DP-06 DOCX 공개 검증 증거

verification.json에는 검증 수·범위·소스/라이브러리/기존 SQL 지문 및 주 DB 원본 열/행 해시를 기록한다. 원문·질문·비밀번호·키·DSN·검출값은 포함하지 않는다. 원본 실행 로그는 src/.runtime에 비공개 보관한다.

최초 회귀337개와 최종 DOCX 집중64개는62개가 중복이다. 추가2개는 DOCX 확정 버전 공유/회수와 여러 XML 부품의 합산 노드 상한이다. 기존 압축비가 먼저 차단하던 텍스트 경계 fixture도 최종 집중에서 수정해 텍스트 상한 자체를 확인했다. 고유 사례339개를 별도 수집 목록과 대조했다. 서버 전체 시험군이 아니라 이번 변경 영향 범위다.

전체 화면83개 중 DX6 신규3개는 개인 문단/RAG/원본 바이트/타 사용자·조직 차단/삭제, DOCX 수집 거부, 관리자 표/행/열/RAG/원본 바이트/위장 확장자를 확인한다. 기존 PDF/TXT/모바일/공유/평가·대화·사용량 회귀도 포함한다.

Word 호환 합성 파일은 일반 python-docx 기본 템플릿의 customXml/썸네일 부품을 시험 자료에서만 제거한 뒤 본문·표가 유지되는지 확인했다. 원래 기본 템플릿은 미지원으로 거부된다. 제품이 사용자 파일을 자동 정리하거나 일반 Word 파일 전체를 지원한다는 의미가 아니다. 격리는 실제 macOS에서 DOCX worker 경로로 프로젝트 읽기·쓰기·네트워크·하위 실행 차단 및 비밀 환경 미전달을 확인했다. RSS 종료 감시는 하드 메모리 상한이 아니다.
