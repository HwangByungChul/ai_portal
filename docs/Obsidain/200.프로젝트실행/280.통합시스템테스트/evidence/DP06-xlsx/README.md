# DP-06 XLSX 공개 검증 증거

verification.json에는 소스/라이브러리/SQL 지문·실제 시험 수·주 DB 원본 열/행 해시를 기록한다. 원문·질문·키·비밀번호·DSN·검출값은 포함하지 않는다. 원본 진단 로그는 src/.runtime에 비공개 보관한다.

서버 변경 영향425개는 기존339개와 신규XLSX86개(파서54/등록18/경계14)의 고유 사례이며 별도 수집 목록과 일치한다. 전체 서버 시험군 통과를 주장하지 않는다. 화면은 전체86개 중 XX6 신규3개를 포함한다. 실제 유료 호출과 기관 환경 검증은 수행하지 않았다.

화면 집중 시험에서 레이블이 업무명에 섞여 질문 근거가 없는 문제가 발견됐다. 셀 주소와 값을 다른 줄로 구성하여 기존 GraphRAG 추출 계약을 유지했고, 최종 화면에서 정확한 값·시트/셀 출처·원본 바이트와 타 사용자/조직 차단·삭제 회수를 확인했다.

일반 Excel 호환 스모크는 openpyxl3.1.5로 만든 기본 합성 파일을 변경 없이 확인했다. 이 라이브러리는 합성 자료 생성 도구이며 제품 runtime 의존성에 추가하지 않았다. 일반 Excel 전체 호환성·서식/계산 재현·OCR 완성을 의미하지 않는다. 단일 부품의 크기와 XML 합산 한도 등 여러 제한을 동시에 적용하므로 개별 최대치 조합 모두를 지원한다고 해석하지 않는다.
