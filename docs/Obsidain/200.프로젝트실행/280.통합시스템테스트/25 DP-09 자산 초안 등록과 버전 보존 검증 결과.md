**실패와 보완을 보존한다.** API 등록 전 수용시험 실패를 먼저 확인했다. 초기 서버47 실행46 통과/1 오류 메시지 누락을 보완했다. 확대시험138의 실패2는 view의 무문맥 RLS 기대값(0행이 올바름), 기존 카탈로그 cardinality(35→37 table/27→28 migration/106→107 policy function)였으며 새 자산의 강제RLS까지 검사 범위를 확대해 재시험했다. 브라우저 초기23의 실패2 중 하나는 복수 조직 선택 누락, 다른 하나는 textarea를 감싼 label에 저장된 값이 섞이는 현상이었다. 명시적 htmlFor/id로 라벨을 수정하고 최종23을 한 번에 재실행해 통과했다. 제품 폼은 조직 전환 시 이전 초안/버전 정보를 제거한다.

증거 폴더: [[200.프로젝트실행/280.통합시스템테스트/evidence/DP09-asset-registry/README]]. backend-summary.json은 안전한 최신 합산, 본시험/재시험/직접시험 JSON은 시도별 결과, browser-results.json은 최종23, migration.json/build.json/smoke.json/cleanup.json/source-hashes.json은 각각 근거다. 민감 원문·암호·DSN·CSRF/쿠키·XML traceback·DB dump는 Vault 증거에 넣지 않았다.
