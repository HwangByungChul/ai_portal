# 개인 파일럿 시연 안내와 피드백 기록

자동 화면 검증을 마쳤다. 실제 사용자가 직접 확인한 편의성·학습 효과는 아직 기록하지 않았다. 이 안내는 **해당 프로젝트가 있는 Mac에서 실행하는 모의 시연**이다. 휴대폰의 `127.0.0.1`은 휴대폰 자체를 가리키므로 지금 휴대폰에서 이 주소로 Mac 화면에 접속할 수 없다. 원격 공개/배포는 이번 작업에 포함하지 않았다.

## 시작·접속·종료

Mac에서 프로젝트의 backend 위치로 이동해 아래 실행 도구를 시작한다. 기존 backend/frontend 또는 자동 화면 시험이 실행 중이면 먼저 해당 실행을 정상 종료한다. 다른 프로세스를 강제로 종료하지 않는다. 도구는 포트8000/5173과 기존 시연 표식을 확인하고 충돌 시 시작을 거부한다.

```sh
cd '/Users/jwpios/antigravity/202610_AI 플랫폼/src/backend'
.venv/bin/python -m scripts.p270_prepare
```

`status: ready`가 표시된 뒤 같은 Mac의 브라우저에서 `http://127.0.0.1:5173`을 연다. 계정 ID/비밀번호는 현재 실행 중 생성되는 `src/backend/.runtime/P270-access-private.md` 파일에서만 확인한다. 공개 문서에는 비밀번호를 적지 않는다. 이 파일은0600, runtime폴더는0700·Git제외다.

- A-ADM: A의 문서·공유·Agent·조직 사용량 관리.
- A-U1: 일반 업무·규정 질문·자신의 개인 자료.
- A-U2: 다른 A사용자, A-U1의 개인 자료는 접근 불가.
- B-ADM/B-U1: B관리/사용, 공유 승인된 A의 정확 버전만 열람.
- DUAL: A/B 전환, 이전 조직 답변이 섞이지 않는지 확인.

준비 자료는 A조직 합성 규정1개와 A-U1 개인 자료1개다. 실제 업로드→Job완료→게시 이후ready를 표시한다. 일반/규정 Agent를 해당 모의 시험 DB에서만 활성화하며 실제 키는 넣지 않는다. 업무 데이터나 원본 평가 정답을 입력하지 않는다.

종료할 때 실행 터미널에서 **Ctrl-C**를 누르고 종료를 기다린다. 도구가 자신의 서버를 종료하고 자신이 만든 시연 DB·원문 저장소·계정/접속 안내 파일을 정리한다. 다음 실행은 새 모의 시연으로 시작하므로 시연 결과 보존이 필요하면 종료 전에 아래 비밀 없는 사용 기록을 작성한다. 기존 프로젝트 기본 DB/실제 모델 원장/등록 키는 변경하지 않는다. 이번 검증 종료 후 서버는 꺼져 있다.

## 직접 따라갈 시연 — 약20~30분의 안내 목표, 실제 소요 미측정

|순서|계정/화면|행동|확인할 화면·의미|
|---|---|---|---|
|1|A-ADM / 문서 관리|합성 규정 게시 상태 확인; 필요 시 새TXT등록|접수됨과 게시됨을 구분; Job완료 후 자료 사용|
|2|A-U1 / AI 업무|일반 대화 Agent로 질문|모의 응답/완료·저장; 일반 답변에 규정 근거를 꾸미지 않음|
|3|A-U1 / 내 사용량·이력|사용량 확인, 새로고침 후 완료 대화 재선택|모의 집계와 실제 청구를 구분; 새 생성 없이 이력 복원|
|4|A-U1 / 규정 Agent|새 대화→규정 Agent→조직 규정 선택→“여신심사 담당 부서는?”|심사1팀·근거보기·정확 원문 다운로드; 지원 문법 기반 시연|
|5|A-ADM / 버전 공유|규정v1을B에 공유하고 v2는 새 버전으로 등록|공유는 정확v1에만 적용; v2를 자동 공유하지 않음|
|6|B-U1 / 규정 Agent|공유v1선택→같은 질문→근거보기|v1본문/근거와 일치; 미공유v2제목·본문 없음|
|7|A-ADM→B-U1|v1공유 회수 후 B 기존 답변·근거·원문 확인|화면은5초/포커스/가시화 재검사, 즉시push가 아님; 서버는 새 접근 차단|
|8|A-U1→A-U2/A-ADM|A-U1 개인 자료 확인; 다른 주체 화면 비교|owner만 개인 제목/내용 열람; 관리 화면은개인문서로 가림|
|9|A-ADM / Agent 관리|일반 Agent중지 후 사용자 화면 새로고침·질문|신규 질문 차단; 기존 저장 결과까지 삭제하는 기능은 아님|
|10|DUAL / 조직 전환·모바일390폭|A/B전환, 별도탭·모바일폭으로 자료/근거 확인|이전 조직 내용 혼입·화면 전체 가로 넘침 없음|

기존 규칙 추출은GR01~10의 명시 문장만 지원한다. 예: “여신심사의 담당 부서는 심사1팀이다.”, “가상참여자의 개인 시연 리허설은 목요일 오전에 진행한다.” 임의 자연어의 모든 관계를 추출하는 제품 수준 GraphRAG가 아니다. 지원되지 않는 문장/관계는 보류할 수 있다. 현재 UI에서 개인 소유자/reader 편집은 제공하지 않으며 준비 도구가 실제 관리 API로 owner를 지정한다. 준비된 개인 문서의 질문 예는 “내 개인 리허설 일정은?”이다.

## 직접 사용 기록 — 사용자 확인 대기

아래에 쿠키·비밀번호·키·개인 문서 본문을 붙이지 않는다. 실제 입력 내용 대신 행동/오류분류만 적는다. 자동 시험 경과를 개인 개발 공수로 옮기지 않는다.

|시작/종료|계정 별칭·조직|행동/완료 여부|막힌 위치·안내 이해도|개선 의견|증거/상태|
|---|---|---|---|---|---|
|미기록|—|직접 사용 미수행|—|—|사용자 확인 대기|

자동시험의 화면 성공은 [[02 전체 흐름 파일럿 결과]]에서 확인한다. 이 기록이 없으면270사용자평가완료로 표시하지 않는다. 실제 모델 RAG 품질은 별도 준비 미완료다.
