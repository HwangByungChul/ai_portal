# 개발 서비스 시작 및 종료 안내

프로젝트에 준비된 기존 개발 데이터베이스와 비공개 서버 설정을 사용한다. 데이터 초기화·seed·migration·패키지 설치·임시 시연 DB 재생성을 자동으로 수행하지 않는다.

## 시작

터미널에서 프로젝트 폴더로 이동한 후 실행한다.

```bash
cd "/Users/jwpios/antigravity/202610_AI 플랫폼"
./src/backend/start.sh
./src/frontend/start.sh
```

백엔드는 전용 데이터베이스가 정지되어 있으면 먼저 구동하고 서버를 시작한다. 프런트엔드는 기존 Node 22.23.1과 설치된 Vite를 사용한다. 두 서비스는 백그라운드로 실행되므로 명령 완료 후 터미널을 닫아도 유지된다.

[사용자 포털](http://127.0.0.1:5173/) · [문서 요약](http://127.0.0.1:5173/document-summary).

## 종료

```bash
cd "/Users/jwpios/antigravity/202610_AI 플랫폼"
./src/frontend/stop.sh
./src/backend/stop.sh
```

각 스크립트는 자신이 등록한 PID와 실행 시각이 일치하는 서비스만 정상 종료한다. 다른 프로그램이 포트를 사용하면 시작을 거부하고, 종료 시 해당 프로그램을 유지한다. 중복 시작은 기존 프로세스를 유지하며, 이미 종료된 서비스에 stop을 다시 실행해도 안전하다.

백엔드 stop은 데이터베이스를 유지한다. 모든 관련 서버를 종료한 뒤 데이터베이스도 종료하려면 별도로 실행한다.

```bash
cd "/Users/jwpios/antigravity/202610_AI 플랫폼/src/backend"
.venv/bin/python -m scripts.devdb stop
```

## 설정·로그

- 서버 설정: `src/backend/.runtime/app.env`의 기존 설정을 사용한다. 실행 쉘에는 API 키·비밀번호·DSN을 복사하지 않았다.
- 사전 준비: backend/.venv, 기존 데이터베이스·app.env, Node 22.23.1, frontend/node_modules가 필요하다.
- 백엔드 로그: `src/backend/.runtime/service-control/service.log`.
- 프런트엔드 로그: `src/frontend/.runtime/service-control/service.log`.
- PID/로그 기록은 Git에서 제외된 .runtime 폴더에 보관한다. 제어 폴더는0700, 로그·PID 기록은0600이다.
- startup 실패나 포트8000/5173 충돌 시 오류 안내와 로그를 확인한다. 다른 프로세스를 강제 종료하지 않는다.
- 기존 임시 시연 환경과 본 개발 데이터베이스는 별도다. [[00 로컬 시연 계정 및 접속 정보 (비공개)]]의 이전 임시 시연 비밀번호가 본 개발 데이터베이스의 비밀번호와 같다고 가정하지 않는다.
