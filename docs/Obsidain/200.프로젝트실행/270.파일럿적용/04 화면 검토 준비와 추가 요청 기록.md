# 화면 검토 준비와 추가 요청 기록

자동 화면 검증64건과 최종 문서9건 재확인, 사용자·문서·사용자관리·Agent·사용량·모바일 캡처6장 저장을 완료했습니다. 직접 사용자 검토는 대기 중입니다. UI/UX 최종 확정이나 추가기능 승인으로 간주하지 않습니다.

현재 [시연 화면](http://127.0.0.1:5173/)은 해당 Mac의 합성 자료/Mock입니다. 로그인 정보는 비공개 `src/backend/.runtime/P270-access-private.md`에 보관합니다. 실제 호출 검증과 시연 데이터는 분리했습니다. 실제 결과/미확인 조건은 [[13 잔여 1~6 작업 검증과 화면 검토 준비 결과]]를 확인해 주세요.

## 검토 순서

1. 일반 사용자: 로그인 → 조직 선택 → 일반 질문/규정 검색 → 답변 근거/원문 → 이력/내 사용량.
2. 조직 관리자: 사용자 관리 → 문서 등록/색인/공유/회수 → Agent 운영 → 조직 사용량/한도.
3. 조직 전환/권한 거부/모바일에서 화면 안내와 가독성 확인.
