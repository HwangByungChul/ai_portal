# C04 검증 증거

C04-tests.json은 최종 전체/관련 pytest 결과다. 관련 시험은 전체에 포함하며 parameter 원문은 case_fingerprint로 대체했다. C04-frontend-regression.json은 build와 기존51개 화면 회귀이며 새 문서/RAG 화면은 C05 범위다. C04-primary-preservation.json은 새014~016 적용·재적용0·기존31테이블·비공개/역사 파일 보존·종료 상태를 기록한다. C04-source-fingerprints.json은 시험 소스 SHA와 로컬 commit을 연결한다. C04-retrieval-contract.json은 실제 구현 경계와 미실행 품질 평가를 구분한다.

모의/고정 가짜 HTTP 전송 검증이다. 실제 provider0·추가비용0·Q20 not_run. 키·DSN·role credential·원문·질문 payload·인용·벡터·private 로그/XML은 포함하지 않는다. 이전 증거를 덮어쓰지 않았다.
