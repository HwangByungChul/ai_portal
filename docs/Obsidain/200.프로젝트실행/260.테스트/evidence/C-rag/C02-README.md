# C02 순수 코어 검증 증거

- C02-test-summary.json: 최종 수량·범위·제약·다음 작업.
- C02-test-results.json: 관련72개와 전체 backend 결과. 관련 시험은 전체에 포함하며 합산하지 않는다.
- C02-corpus-plan.json: 원문7버전에서 실제 생성한 처리 계획을 평가 기대값과 별도로 대조한 ID/수량/원문 구간/해시. 본문·비공개 제목·label/quote를 포함하지 않는다.
- C02-source-fingerprints.json: 실제 시험 소스 지문과 로컬 commit 연결.
- C02-preservation.json: 최종 보존·비밀·primary·종료 상태 확인.

실제 임베딩/벡터 저장·문서API·Job·검색·RAG·Q20 완료 증거가 아니다. private 원문/XML/log는 공개 증거에 넣지 않는다. 이전 C01 증거는 수정하지 않는다.
