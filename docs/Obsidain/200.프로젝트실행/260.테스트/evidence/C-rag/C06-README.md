# C06 합성 자료·Q20 검증 증거

2026-10-06. 모의 공급자와 실제 API/PostgreSQL/원문 저장소에서 합성7버전 등록→색인→Q20 평가→회수/삭제→native API 재시작을 검증했다. Q20 **20/20 기대 결과 통과**다. 정답 manifest는 실행 후 evaluator 대조에만 쓰며 runtime 질문에는 prompt/정확한 요청 버전/요청ID만 전달한다.

서버 전체747개/관련36개 통과(중복 합산 안 함), 빌드와 기존 화면60개 통과. 전체 서버 시험 후 평가 도우미에 추가한 읽기 전용 색인 대조는 최종 native Q20와 단위 시험에서 별도 검증했다. 제품 검색/코어는 전체 회귀 이후 동일 소스다.

- `C06-evaluation-results.json`:7버전/18근거/16관계·Q20별 상태/판정·권한/재시작/정산.
- `C06-test-summary.json`, `C06-test-results.json`:실제 시험 범위/식별자·초기 결함과 최종 결과.
- `C06-real-preflight.json`:기존500원/내부0.19원·예약/중지·모델 단가 확인 및 실제 평가 blocked 사유.
- `C06-preservation.json`:기존 데이터/키/원장/증거·원본 보존과 정리 상태.
- `C06-source-fingerprints.json`:시험 소스 지문/로컬 커밋.

실제 RAG/임베딩 품질은 미평가이며 Q20 원본은 not_run을 유지한다. 이 파일의 실행 결과와 원본의 작성 상태를 구분한다. 추가 유료0회/비용0원; mock 원장1.58원은 시험상 내부 추정이며 공급자 지출이 아니다. 공개 파일에 원문·질문·답변·키·쿠키·비밀번호·DSN을 넣지 않는다.
