## 본문·위험 입력·격리

한글·빈 문단 번호·표 셀·코드포인트 오프셋을 확인했다. 경로/중복/심볼릭 링크/위장 ZIP·미지원 부품·외부 관계·DTD/엔터티·처리 지시·변경 추적·그림/필드/숨김/자동 번호·중첩/병합 표·형식 메타데이터에 숨은 본문을 거부한다. 부품 수/개별 해제/압축비·XML 깊이·합산 노드·텍스트·단위 수를 검증했다. UTF-16 XML은 현재 지원하지 않아 안전한 형식 오류로 거부한다.

DOCX worker의 실제 macOS 격리 경로로 프로젝트 읽기·쓰기·통신·하위 실행 차단과 비밀 환경 미전달을 확인했다. 공통 자원 실행기의 RSS 초과/감시 실패 시험은 기존 PDF 회귀에 포함했고 DOCX 안전한 오류로의 변환도 확인했다.

## 접수·무결성·공유

개인/관리자 원본 바이트와 두 SHA, 확정 재접수 파서0회, 파싱 전 권한 차단, 파싱 중 권한 회수, 제목/본문/표 개인정보 후보 거부(저장·작업·호출0), 동시 접수 한 작업, 감사 실패 후 파일0600 및 같은ID 복구를 확인했다. 원본 변조/유실·위치/지문 변조는 차단하고 두 파일을 정리한다. DOCX v1 공유 뒤 v2를 생성해도 수신 조직은 v1만 조회하고, 회수 후 목록에서 제거된다.

Word 호환 합성 파일의 기본 customXml/썸네일 부품을 시험 자료에서만 제거한 별도 스모크 검증도 통과했다. 기본 파일 전체 호환성은 검증 완료로 표시하지 않는다. 개인정보 최소 정책의 기존 오탐/미탐 한계는 PDF 결과와 동일하며 일반 정책 플랫폼 완성을 의미하지 않는다.
