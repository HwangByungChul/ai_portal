# 회의록 문서 자료 날짜 처리 및 품질 평가 상세 개발 계획

**Goal:** AGENT_03에 권한있는 문서자료·회의일·안전한 상대기한 처리와 품질평가를 실제 실행/결과화면까지 연결한다.
**Architecture:** 서버 소유 입력·근거·날짜 계약을 확장하고 exact 문서 version/SHA/접근권한을 실행 원장에 봉인한다. 현재 Workflow/Agent 호출·비용/취소·승인/RLS를 재사용하며 신규SQL만 추가한다. 의미품질과 기술조건을 구분하고 실제run에 대한 사람의 평가를 기록한다.
**Tech Stack:** Python/Pydantic/PostgreSQL, React/TypeScript, pytest/Playwright, Node22.
**Spec:** [[31 업무 Agent 10종 승인 연결 상세 작업 계획]], [[32 관리 B안 Tool Workflow 승인 화면 확장 상세 작업 계획]], [[2026-10-15 기존 계정 데이터 보존 및 040 개발 보류 해소 보고서]].

## 결정과 대안 검토

사용자가'문서자료선택/회의일·상대날짜/실제회의록품질' 진행을 승인했다. 자유로운 날짜 추론은 근거없는 기한을 만들 수 있고 달력/영업일 통합은 기관휴일 기준이 없어 범위를 확대한다. 이번에는 명시적 회의일과 결정적 달력규칙·확인불가표시를 권장/채택한다. 품질은구조/인용/날짜검사+사람평가이며 실제모델벤치마크를무단유료호출하거나 mock통과를실제품질합격으로표시하지않는다. 사용자 품질우선기준 질문은 선택적이며 답변전에는정확성/누락/담당자/기한을모두평가한다.
