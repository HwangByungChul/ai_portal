# 기존 개발 DB 원본 복구 및 최신 기능 이행 계획

**Goal:** 기존 계정·비밀번호·자료를 유지한 채 최신 API/화면을 기존 개발 DB에서 구동한다.
**Architecture:** 적용 이력 checksum과 정확히 일치하는 과거 SQL을 복구하고 비공개 백업을 별도 복원 DB에서 시험한다. 기존 이력 수정/검증 우회/재seed 없이 정상 migration runner로 신규 SQL만 이행한다.
**Tech Stack:** PostgreSQL/pg_dump/pg_restore, 기존 fixture DB marker·migration runner·service_control, Python.
**Spec:** [[23 포털 UI UX 확정과 사이트 분리 검토]], [[2026-10-14 관리 B Tool Workflow 승인 확장 구현 보고서]].

사용자는 기존 DB 문제 해결과 기존 계정 기반 테스트를 승인했다. 테스트 harness는 현재 실행 중이며 이행 시험 전 소유프로세스를 정상 종료하고 공용 역할/fixture 작업은 순차 진행한다. 유료모델호출/운영배포/나머지9종 확장은 범위 밖이다.

## Task1 원본 복구·백업·복원본 이행 시험
- [ ] 현재 primary 기록/파일hash·실제 DB 함수와 후보 원본을 읽기 대조한다. 040 원본을 checksum완전일치 없이 추정하여 적용하지 않는다. backup/git/archived bytes와정확한DB함수차이를조사한다.
- [ ] 원본 복구가확인되면 현재소스와 원본을각각보존한다. 검토된정확원본복원은기존파일의의도적rewrite가아니라적용이력보존이다. 필요한기능수정은새번호migration으로분리한다. checksum이력값수정/검사완화금지.
- [ ] 기존 DB 및 app.env/계정 파일을0600비공개 백업한다. backup을별도marker복원DB로읽어무결성과복구가능성을검증한다. 비밀번호/DSN/원문을공개보고하지않는다.
- [ ] 복원본에최신 migration을순차적용하고기존행/열·기록checksum·계정passwordhash·문서/파일설정 보존을검증한다. source/SQL차이는scoped검토를받고실패원인수정뒤재시험한다.

## Task2 기존 DB 이행·서비스 복구·수용 기록
- [ ] 시험/검토통과 후기존DB를정상runner로원자이행한다. backup/restored시험결과와활성/미정산작업검사를선행한다. 기존계정/비밀번호/DSN/HMAC·개인자료를재초기화하지않는다.
- [ ] 기존설정으로8000/5173/5174구동하고health·기존login·역할별신규관리API/currentfeature읽기를실제확인한다. 유료실행0.
- [ ] 실패시원자rollback/소유서비스정리와데이터보존을확인한다. 데이터손실복원을기존데이터위에자동덮어쓰기하지않는다.
- [ ] 결과를구현보고/설계23/진행02에기록한다. 원본미확인 또는실시험불통과이면그조건을명시하고기본DB이행을보류한다.

## 2026-10-14 · 원본 byte 미확인 시 비파괴 이관 대안

원본DB를직접이행하는Task2는040정확원본이없어보류한다. 사용자목적은기존계정/비밀번호/자료로최신기능을테스트하는것이므로원본DB와원래schema_migrations를그대로보존한채별도새개발DB에기존데이터를이관하는대안을추가한다. 이는원본checksum수정이나runner검증우회가아니다. 새DB는현재SQL000~040을정상적용하고새적용이력을기록하며, 원본DB데이터를원본과같은테이블/열로옮긴뒤정상runner로041~050을추가적용한다. 기존원장checksum과53표데이터/계정hash는비공개백업및원본DB/출처증거로보존한다.

추가단계: 정확pre/post원장·관계/sequence·53표oldcolumn/allrowdigest검증→현재계정실제login/role/newAPI읽기검증→scoped코드검토→기존app.env의DB대상만새DB로원자전환(원본설정백업/HMAC/키/mode/계정비밀번호보존)→8000/5173/5174구동·수용. 원본DB는삭제/덮어쓰기하지않고rollback은설정복구로가능하게한다. 새DB에재seed하지않고데이터이관으로기존계정을보존한다. 이관DB검증이실패하면전환하지않는다. 유료실행/운영배포/미정산원장수정은금지한다. 이전Task2의원본직접이행과다른방법임을최종보고에명시한다.
