## 2. 거버넌스 제외 적용

- **제외:** F-050~F-060 11개, `SCR-GOV-*`35개, 거버넌스 위험평가/Flow/단계결재/연간 의무모니터링/법규 최신화/거버넌스 보고서와 해당 전용 데이터·흐름.
- **유지:** 사용자/관리자 포털의 인증·권한·Tenant·PII/가드레일·운영 감사·배포승인·과제결재·사용량 통제. 해당 요구는 F-001~049와 관리자 IA에 별도로 존재합니다.
- **혼합 항목:** F-002의 거버넌스 앱 디자인 적용은 제외. F-040은 관리자 보안정책·Scope·감사 영역만 유지. 공통 승인함/알림/Job의 F-050~060 참조는 제거하고 사용자/관리자 업무만 비교합니다. 역할명에 “보안·거버넌스”가 있다고 관리자 보안 화면 전체를 삭제하지 않습니다.
- **일정:** 이전 요청대로 마감·기간 제약 없이 비교합니다. 원본의8개월 계획·M1~M8은 구현 증거나 이번 일정으로 적용하지 않습니다.

## 4. 현재 실동작과 제안의 차이

| 영역 | 현재 확인 범위 | 제안 대비 추가 범위 |
|---|---|---|
| 인증/포털 | 로컬 로그인·세션/CSRF·복수소속·3role·같은SPA 권한별 메뉴 | SSO/AD·8역할·SOD·별도 사용자/관리자 앱·Home/알림/도움말 |
| API/AI Gateway | FastAPI 인증/tenant/요청한도·AI4작업 중앙허가/비용·고정 공급자 | 외부 레거시 인증·다중모델 routing·Tool/credential gateway·가드레일 engine |
| 대화 | 고정 `general`, `rules_rag`·SSE/취소/이력·저장확인 | 첨부·재생성·이력 이름/검색/핀/삭제·사용자 평가·출력 |

| 운영/비용 | 본인/조직/project usage·reserved/unknown·stop/cap·receipt·내부추정 | GPU/CPU/모델성능·장애관제·기간추이·Export·부서/Agent 집계·청구확정 |

| 배포/복원 | 로컬 개발/모의 시연·동일DB 재시작/비용 보존 | 승인 릴리스·환경승격·K8s/HA/Canary·backup별도restore·DR/RTO/RPO |

제안은 Next.js/Spring Boot/FastAPI 및 Private LLM·10계열사 Cell을 기준으로 하고, 현재 개인 MVP는 React/Vite/FastAPI/PostgreSQL·공유 서버 논리 격리·OpenAI 실험입니다. 이는 **기술/운영 기준의 차이**입니다. Spring Boot나Private LLM을 도입하지 않았다는 사실과 사용자 기능이 부족한 사실을 분리합니다. 원본에서 Public LLM 운영 연결은 최초오픈 제외했으므로 현재OpenAI 실험을 제안 Private 서빙 요건의 충족으로 처리하지 않습니다.

## 7. 검증 결과의 적용 범위

기존 MVP 전체 서버949건·추가 경계18건·최종 retry추적 영향27건, 브라우저64건·문서화면9건이 통과했습니다. 전체949를 최종 수정 이후 재실행한 것으로 주장하지 않습니다. 기존 동일 primary의 추가 actual8회는4작업 각2회, 정상A/B규정 답변 각1개 대표 검증이며 제안 전체 Agent·기능 검수는 아닙니다.

현재 T280 상세60은44 pass/16 not_run, ACL16은11 pass/5 not_run, V41 하위143은135 pass/8 not_run입니다. **이 상세60은 제안 F60과 다른 검증 분류**입니다. 제안 F-001~049에 자동으로 통과를 이식하거나 합격률로 계산하지 않습니다. 실제Q20 전체·성능 p95/부하·10tenant 병렬격리·새 환경 설치/백업복원·HA/DR·직접사용자 수용은 별도입니다. 기준 보고서는 [[13 잔여 1~6 작업 검증과 화면 검토 준비 결과]]입니다.

이번 작업은 문서/코드 정적 대조와 기존 증거 검토입니다. 새 테스트·유료 모델호출·제품 수정은 수행하지 않았습니다. 원본 엑셀/설계자료/현재소스/이전 증거는 수정하지 않았습니다.
