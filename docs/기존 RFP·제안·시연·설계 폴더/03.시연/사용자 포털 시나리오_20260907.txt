ㅇ 프롬프트 질문 - 첨부 문서를 기반으로 AI에게 질문하고 답변을 확인
1. '회의록_2026.09.04.txt' 파일 첨부
2. "2026년 9월 4일 회의에서 결정된 사항을 정리해줘" 프롬프트 입력
3. 답변 확인

ㅇ AI 문서함 - AI 문서함의 문서를 참조하여 질의하고 원문 확인
1. AI 문서함 클릭
2. 위 프롬프트 질문에서 첨부했던 문서 확인
3. AI 문서 참조 활성화후 질문
4. "2026년 마케팅 결산 보고 파일 요약해줘" 프롬프트 입력
5. 답변내 숫자로 된 링크 버튼 하나 클릭
6. 왼쪽 문서 확인

ㅇ 피드백 - AI 답변에 대한 사용자 피드백 등록
1. AI 문서함 답변에서 아래 손가락 표시 클릭
2. 열린 모달창에서 피드백 입력
3. 답변에 손가락 색상 바뀐거 확인

ㅇ 기록 확인 - 이전 채팅 기록 조회 및 삭제
1. 왼쪽 사이드바 기록 항목 하나 클릭
2. 기록 휠을 아래로 내려 모두보기 클릭
3. 채팅 기록 항목중 하나 ... 클릭하여 삭제

ㅇ 검색 - 채팅 및 문서 내 검색 결과 확인
1. 상단 검색바에 "2026"검색
2. 검색 결과 항목 하나 클릭
3. 검색 결과 확인 (문서, 채팅 검색 결과 각각 확인)

ㅇ 에이전트 활용 - 회의 보조 에이전트를 이용하여 회의록 및 스크립트 생성
1. 오른쪽 사이드바 회의 보조 클릭
2. 회의 정보 입력
3. 왼쪽에 생성된 회의록 및 스크립트 확인

ㅇ 에이전트 추가 - 원하는 에이전트를 사이드바에 추가,제거
1. 왼쪽사이드바 '+' 클릭
2. 에이전트 추가 모달창에서 왼쪽 사이드바에 추가 또는 제거 하고 싶은 항목 핀 버튼 클릭
3. 왼쪽 사이드바 추가 및 제거 확인

ㅇ 챗봇 - 챗봇을 통해 서비스 이용 방법 안내
1. 오른쪽 하단 챗봇 아이콘 클릭
2. "에이전트 추가해서 사용하는 방법 알려줘" 클릭
3. 답변 확인
